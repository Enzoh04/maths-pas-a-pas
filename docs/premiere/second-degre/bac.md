## Sujet 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** Le discriminant du trinôme $x^2 - 4x + 1$ est :

a. $12$ ; b. $20$ ; c. $-12$ ; d. $4$.

**Question 2.** Pour tout réel $x$, $x^2 + 2x - 3$ est égal à :

a. $(x + 1)^2 - 3$ ; b. $(x + 1)^2 - 4$ ; c. $(x - 1)^2 - 4$ ; d. $(x + 2)^2 - 3$.

**Question 3.** Augmenter $40$ de $15\,\%$ donne :

a. $46$ ; b. $55$ ; c. $40{,}15$ ; d. $34$.

**Question 4.** L'ensemble des solutions de l'équation $2x^2 - 8 = 0$ est :

a. $\{4\}$ ; b. $\{-2\,;\,2\}$ ; c. $\{2\}$ ; d. $\{-4\,;\,4\}$.

**Question 5.** Les trois quarts de $60$ valent :

a. $15$ ; b. $40$ ; c. $45$ ; d. $80$.

**Question 6.** La parabole d'équation $y = -(x - 1)^2 + 4$ a pour sommet :

a. $(-1\,;\,4)$ ; b. $(1\,;\,-4)$ ; c. $(1\,;\,4)$ ; d. $(4\,;\,1)$.

### Partie 2 — Exercice

Soit $f$ la fonction définie sur $\mathbb{R}$ par $f(x) = -2x^2 + 8x - 6$. On note $\mathcal{C}$ sa courbe représentative.

1. Calculer $f(0)$.
2. a. Montrer que, pour tout réel $x$, $f(x) = -2(x - 2)^2 + 2$.
   b. En déduire le tableau de variations de $f$ et son extremum.
3. a. Résoudre l'équation $f(x) = 0$.
   b. En déduire une forme factorisée de $f(x)$.
   c. Dresser le tableau de signes de $f(x)$.
4. Résoudre l'équation $f(x) = -6$.
5. Soit $d$ la droite d'équation $y = 2x - 6$. Déterminer les coordonnées des points d'intersection de $\mathcal{C}$ et de $d$, puis la position relative de $\mathcal{C}$ et de $d$.

??? success "Correction"
    **Partie 1**

    1. **a.** $16 - 4 = 12$.
    2. **b.** $(x + 1)^2 = x^2 + 2x + 1$, donc $x^2 + 2x - 3 = (x + 1)^2 - 4$.
    3. **a.** $40 \times 1{,}15 = 46$.
    4. **b.** $x^2 = 4$.
    5. **c.** $\frac{3}{4} \times 60 = 45$.
    6. **c.** Forme canonique $a(x - \alpha)^2 + \beta$ avec $\alpha = 1$, $\beta = 4$.

    **Partie 2**

    **1.** $f(0) = -6$.

    **2. a.** $-2(x - 2)^2 + 2 = -2(x^2 - 4x + 4) + 2 = -2x^2 + 8x - 6$.

    **b.** $a = -2 < 0$ : $f$ est croissante sur $]-\infty\,;\,2]$ et décroissante sur $[2\,;\,+\infty[$. Son maximum vaut $2$, atteint en $x = 2$.

    **3. a.** $\Delta = 64 - 48 = 16$, racines $\frac{-8 - 4}{-4} = 3$ et $\frac{-8 + 4}{-4} = 1$. $S = \{1\,;\,3\}$.

    **b.** $f(x) = -2(x - 1)(x - 3)$.

    **c.** $a < 0$ : $f(x)$ est négatif sur $]-\infty\,;\,1[$ et sur $]3\,;\,+\infty[$, positif sur $]1\,;\,3[$, nul en $1$ et $3$.

    **4.** $f(x) = -6 \iff -2x^2 + 8x = 0 \iff -2x(x - 4) = 0 \iff x = 0$ ou $x = 4$.

    **5.** $f(x) - (2x - 6) = -2x^2 + 6x = -2x(x - 3)$. Points d'intersection : $(0\,;\,-6)$ et $(3\,;\,0)$. Cette différence est positive sur $]0\,;\,3[$ : $\mathcal{C}$ est au-dessus de $d$ sur $]0\,;\,3[$, et en dessous sur $]-\infty\,;\,0[$ et sur $]3\,;\,+\infty[$.

## Sujet 2

### Partie 1 — Automatismes (QCM)

**Question 1.** Pour tout réel $x$, $(2x + 3)^2$ est égal à :

a. $4x^2 + 9$ ; b. $4x^2 + 6x + 9$ ; c. $4x^2 + 12x + 9$ ; d. $2x^2 + 12x + 9$.

**Question 2.** Le trinôme $-x^2 + 1$ est positif ou nul sur :

a. $[-1\,;\,1]$ ; b. $]-\infty\,;\,-1] \cup [1\,;\,+\infty[$ ; c. $\mathbb{R}$ ; d. $[0\,;\,1]$.

**Question 3.** L'équation $x^2 + 4 = 0$ :

a. a deux solutions $-2$ et $2$ ; b. a une solution $-4$ ; c. n'a pas de solution réelle ; d. a une solution $2$.

**Question 4.** Un article coûte $80$ €. Après une baisse de $25\,\%$, il coûte :

a. $55$ € ; b. $60$ € ; c. $64$ € ; d. $20$ €.

**Question 5.** On lance un dé équilibré à six faces. La probabilité d'obtenir un multiple de $3$ est :

a. $\frac{1}{6}$ ; b. $\frac{1}{3}$ ; c. $\frac{1}{2}$ ; d. $\frac{2}{3}$.

**Question 6.** $\dfrac{1}{2} + \dfrac{1}{3}$ est égal à :

a. $\frac{2}{5}$ ; b. $\frac{1}{5}$ ; c. $\frac{5}{6}$ ; d. $\frac{1}{6}$.

### Partie 2 — Exercice

Un jardinier dispose de $40$ mètres de grillage pour clôturer un potager rectangulaire, le long d'un mur. Le côté adossé au mur ne nécessite pas de grillage. On note $x$ la longueur (en mètres) de chacun des deux côtés perpendiculaires au mur.

1. Justifier que $0 < x < 20$ et que la longueur du côté parallèle au mur est $40 - 2x$.
2. Montrer que l'aire du potager est $A(x) = -2x^2 + 40x$.
3. Pour quelle valeur de $x$ l'aire est-elle maximale ? Donner les dimensions du potager et son aire.
4. Le jardinier veut une aire d'au moins $150$ m².
   a. Montrer que cela revient à résoudre $x^2 - 20x + 75 \leq 0$.
   b. Résoudre cette inéquation et conclure.

??? success "Correction"
    **Partie 1**

    1. **c.** $(2x)^2 + 2 \times 2x \times 3 + 9$.
    2. **a.** $a < 0$, racines $-1$ et $1$ : positif entre les racines.
    3. **c.** $x^2 = -4$ est impossible.
    4. **b.** $80 \times 0{,}75 = 60$.
    5. **b.** Deux faces sur six : $3$ et $6$.
    6. **c.** $\frac{3}{6} + \frac{2}{6}$.

    **Partie 2**

    **1.** Le grillage couvre deux côtés de longueur $x$ et un côté parallèle au mur : $2x + L = 40$, donc $L = 40 - 2x$. Les longueurs étant strictement positives, $x > 0$ et $40 - 2x > 0$, soit $x < 20$.

    **2.** $A(x) = x(40 - 2x) = -2x^2 + 40x$.

    **3.** $a = -2 < 0$ : maximum en $\alpha = \frac{-40}{-4} = 10$, qui est bien dans $]0\,;\,20[$. Les dimensions sont $10$ m et $20$ m, pour une aire de $A(10) = 200$ m².

    **4. a.** $-2x^2 + 40x \geq 150 \iff -2x^2 + 40x - 150 \geq 0 \iff x^2 - 20x + 75 \leq 0$ (on divise par $-2 < 0$ : l'inégalité change de sens).

    **b.** $\Delta = 400 - 300 = 100$, racines $\frac{20 - 10}{2} = 5$ et $\frac{20 + 10}{2} = 15$. Le trinôme ($a = 1 > 0$) est négatif ou nul entre les racines : $x \in [5\,;\,15]$. Le jardinier doit choisir $x$ entre $5$ et $15$ mètres.

## Sujet 3

### Partie 1 — Automatismes (QCM)

**Question 1.** La somme des racines du trinôme $2x^2 - 6x + 1$ est :

a. $-3$ ; b. $3$ ; c. $\frac{1}{2}$ ; d. $6$.

**Question 2.** Le produit des racines du trinôme $2x^2 - 6x + 1$ est :

a. $\frac{1}{2}$ ; b. $2$ ; c. $-3$ ; d. $1$.

**Question 3.** $\sqrt{50}$ est égal à :

a. $25$ ; b. $5\sqrt{2}$ ; c. $2\sqrt{5}$ ; d. $10\sqrt{5}$.

**Question 4.** Deux baisses successives de $10\,\%$ correspondent à un coefficient multiplicateur de :

a. $0{,}8$ ; b. $0{,}81$ ; c. $0{,}9$ ; d. $1{,}21$.

**Question 5.** $(u_n)$ est arithmétique de premier terme $u_0 = 2$ et de raison $3$. Alors $u_4$ vaut :

a. $12$ ; b. $14$ ; c. $162$ ; d. $11$.

**Question 6.** L'ensemble des solutions de l'inéquation $x^2 < 9$ est :

a. $]-\infty\,;\,3[$ ; b. $]-3\,;\,3[$ ; c. $]-\infty\,;\,-3[ \cup\, ]3\,;\,+\infty[$ ; d. $]-9\,;\,9[$.

### Partie 2 — Exercice

**A. Question de cours.** Soit $a$, $b$, $c$ trois réels avec $a \neq 0$ et $\Delta = b^2 - 4ac$.

1. Montrer que, pour tout réel $x$, $ax^2 + bx + c = a\left[\left(x + \dfrac{b}{2a}\right)^2 - \dfrac{\Delta}{4a^2}\right]$.
2. En déduire que si $\Delta < 0$, l'équation $ax^2 + bx + c = 0$ n'a pas de solution, et que si $\Delta > 0$, elle en a deux, que l'on exprimera.

**B. Une équation à paramètre.** Pour tout réel $m$, on considère l'équation $(E_m)$ : $x^2 - 2x + m = 0$.

1. Résoudre $(E_{-3})$.
2. Selon les valeurs de $m$, déterminer le nombre de solutions de $(E_m)$.
3. Déterminer $m$ pour que $2$ soit solution de $(E_m)$, puis trouver l'autre solution sans calculer de discriminant.

??? success "Correction"
    **Partie 1**

    1. **b.** $-\frac{b}{a} = \frac{6}{2} = 3$.
    2. **a.** $\frac{c}{a} = \frac{1}{2}$.
    3. **b.** $\sqrt{25 \times 2} = 5\sqrt{2}$.
    4. **b.** $0{,}9^2 = 0{,}81$.
    5. **b.** $2 + 4 \times 3 = 14$.
    6. **b.** $x^2 - 9 < 0$ entre les racines $-3$ et $3$.

    **Partie 2**

    **A.** Voir le cours, § 4.

    **1.** $a\left(x + \frac{b}{2a}\right)^2 = ax^2 + bx + \frac{b^2}{4a}$, et $a \times \frac{\Delta}{4a^2} = \frac{b^2 - 4ac}{4a} = \frac{b^2}{4a} - c$. La différence vaut $ax^2 + bx + c$.

    **2.** L'équation équivaut à $\left(x + \frac{b}{2a}\right)^2 = \frac{\Delta}{4a^2}$. Si $\Delta < 0$, le membre de droite est strictement négatif et un carré ne peut pas l'être : pas de solution. Si $\Delta > 0$, on obtient $x + \frac{b}{2a} = \pm\frac{\sqrt{\Delta}}{2a}$, soit $x = \frac{-b \pm \sqrt{\Delta}}{2a}$.

    **B. 1.** $x^2 - 2x - 3 = (x - 3)(x + 1)$ : $S = \{-1\,;\,3\}$.

    **2.** $\Delta = 4 - 4m$. Deux solutions si $m < 1$ ; une solution ($x = 1$) si $m = 1$ ; aucune si $m > 1$.

    **3.** $4 - 4 + m = 0 \iff m = 0$. La somme des racines de $x^2 - 2x$ vaut $2$, donc l'autre solution est $0$. (On le voit aussi en factorisant : $x(x - 2) = 0$.)

## Sujet 4

### Partie 1 — Automatismes (QCM)

**Question 1.** Un trinôme a un coefficient $a < 0$ et un discriminant $\Delta < 0$. Alors :

a. il est toujours positif ; b. il est toujours strictement négatif ; c. il change de signe ; d. il s'annule une fois.

**Question 2.** Pour tout réel $x$, $(x - 5)(x + 2)$ est égal à :

a. $x^2 - 3x - 10$ ; b. $x^2 + 3x - 10$ ; c. $x^2 - 7x - 10$ ; d. $x^2 - 10$.

**Question 3.** $30\,\%$ de $200$ vaut :

a. $6$ ; b. $30$ ; c. $60$ ; d. $600$.

**Question 4.** $10^3 \times 10^{-5}$ est égal à :

a. $10^{-15}$ ; b. $10^{-2}$ ; c. $10^{8}$ ; d. $10^{2}$.

**Question 5.** L'ensemble des solutions de l'équation $(x - 1)(x + 4) = 0$ est :

a. $\{1\,;\,4\}$ ; b. $\{-1\,;\,4\}$ ; c. $\{1\,;\,-4\}$ ; d. $\{-1\,;\,-4\}$.

**Question 6.** Le coefficient directeur de la droite passant par $A(0\,;\,1)$ et $B(2\,;\,5)$ est :

a. $\frac{1}{2}$ ; b. $2$ ; c. $4$ ; d. $3$.

### Partie 2 — Exercice

Soit $f(x) = x^2 - 2x - 3$ et $g(x) = x + 1$, définies sur $\mathbb{R}$. On note $\mathcal{C}_f$ et $\mathcal{C}_g$ leurs courbes.

1. Factoriser $f(x)$.
2. a. Montrer que $f(x) - g(x) = (x + 1)(x - 4)$.
   b. En déduire les coordonnées des points d'intersection de $\mathcal{C}_f$ et $\mathcal{C}_g$.
   c. Étudier la position relative de $\mathcal{C}_f$ et $\mathcal{C}_g$.
3. On considère l'inéquation $(I)$ : $\dfrac{f(x)}{g(x)} \geq 0$.
   a. Pour quelle valeur de $x$ le quotient n'est-il pas défini ?
   b. Simplifier $\dfrac{f(x)}{g(x)}$ pour $x \neq -1$, puis résoudre $(I)$.
4. Compléter la fonction Python suivante, qui renvoie `True` si la courbe de $f$ est au-dessus de celle de $g$ (ou la touche) en $x$, et `False` sinon.

    ```python
    def au_dessus(x):
        f = x**2 - 2*x - 3
        g = ...
        return ...
    ```

??? success "Correction"
    **Partie 1**

    1. **b.** $\Delta < 0$ : signe de $a$, sans s'annuler.
    2. **a.** $x^2 + 2x - 5x - 10$.
    3. **c.** $0{,}3 \times 200 = 60$.
    4. **b.** $10^{3 - 5}$.
    5. **c.** Équation produit nul.
    6. **b.** $\frac{5 - 1}{2 - 0} = 2$.

    **Partie 2**

    **1.** Racines $-1$ et $3$ (somme $2$, produit $-3$) : $f(x) = (x + 1)(x - 3)$.

    **2. a.** $f(x) - g(x) = x^2 - 3x - 4$, et $(x + 1)(x - 4) = x^2 - 3x - 4$.

    **b.** $x = -1$ ou $x = 4$. Points $(-1\,;\,0)$ et $(4\,;\,5)$.

    **c.** $(x + 1)(x - 4)$ est positif à l'extérieur des racines : $\mathcal{C}_f$ est au-dessus de $\mathcal{C}_g$ sur $]-\infty\,;\,-1[$ et sur $]4\,;\,+\infty[$, en dessous sur $]-1\,;\,4[$.

    **3. a.** Pour $x = -1$, car $g(-1) = 0$.

    **b.** Pour $x \neq -1$, $\dfrac{(x + 1)(x - 3)}{x + 1} = x - 3$. Donc $(I) \iff x - 3 \geq 0$ et $x \neq -1$, c'est-à-dire $S = [3\,;\,+\infty[$.

    **4.** `g = x + 1` et `return f >= g`.
