## Sujet 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** Un angle de $120°$ mesure, en radians :

a. $\frac{\pi}{3}$ ; b. $\frac{2\pi}{3}$ ; c. $\frac{3\pi}{4}$ ; d. $\frac{5\pi}{6}$.

**Question 2.** $\sin\frac{\pi}{4}$ est égal à :

a. $\frac{1}{2}$ ; b. $\frac{\sqrt{3}}{2}$ ; c. $\frac{\sqrt{2}}{2}$ ; d. $1$.

**Question 3.** La mesure principale de $\frac{9\pi}{4}$ est :

a. $\frac{\pi}{4}$ ; b. $-\frac{\pi}{4}$ ; c. $\frac{3\pi}{4}$ ; d. $2\pi$.

**Question 4.** Dans un triangle rectangle, l'hypoténuse mesure $10$ et l'un des côtés de l'angle droit mesure $6$. L'autre côté mesure :

a. $4$ ; b. $8$ ; c. $\sqrt{136}$ ; d. $16$.

**Question 5.** $\left(\dfrac{\sqrt{3}}{2}\right)^2 + \left(\dfrac{1}{2}\right)^2$ est égal à :

a. $1$ ; b. $\frac{\sqrt{3} + 1}{2}$ ; c. $\frac{3}{2}$ ; d. $\frac{1}{2}$.

**Question 6.** Une suite arithmétique a pour premier terme $u_0 = 10$ et pour raison $-3$. Alors $u_5$ vaut :

a. $-5$ ; b. $25$ ; c. $-15$ ; d. $7$.

### Partie 2 — Exercice

**A. Question de cours.** Soit $M$ le point du cercle trigonométrique associé au réel $\frac{\pi}{3}$.

1. Démontrer que le triangle $OIM$ est équilatéral.
2. En déduire que $\cos\frac{\pi}{3} = \frac{1}{2}$, puis que $\sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$.

**B. Application.**

1. Calculer $\cos\frac{2\pi}{3}$, $\sin\left(-\frac{\pi}{3}\right)$, $\cos\frac{4\pi}{3}$ et $\sin\frac{4\pi}{3}$.
2. Résoudre dans $]-\pi\,;\,\pi]$ l'équation $\cos x = -\frac{1}{2}$.
3. Résoudre dans $]-\pi\,;\,\pi]$ l'inéquation $\sin x \geq \frac{\sqrt{3}}{2}$.

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **c.** 3. **a.** $\frac{9\pi}{4} = 2\pi + \frac{\pi}{4}$. 4. **b.** $\sqrt{100 - 36}$. 5. **a.** 6. **a.** $10 - 15$.

    **Partie 2**

    **A. 1.** $OI = OM = 1$ : le triangle est isocèle en $O$, avec un angle de $60°$ en $O$. Les deux autres angles sont égaux, de somme $120°$ : ils mesurent $60°$. Le triangle est équilatéral.

    **2.** La hauteur issue de $M$ est aussi la médiane : le projeté $H$ de $M$ sur $(OI)$ est le milieu de $[OI]$, donc $\cos\frac{\pi}{3} = OH = \frac{1}{2}$. Puis $\sin^2\frac{\pi}{3} = 1 - \frac{1}{4} = \frac{3}{4}$, et $\sin\frac{\pi}{3} > 0$, donc $\sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$.

    **B. 1.** $\cos\frac{2\pi}{3} = -\frac{1}{2}$ ; $\sin\left(-\frac{\pi}{3}\right) = -\frac{\sqrt{3}}{2}$ ; $\cos\frac{4\pi}{3} = \cos\left(\pi + \frac{\pi}{3}\right) = -\frac{1}{2}$ ; $\sin\frac{4\pi}{3} = -\frac{\sqrt{3}}{2}$.

    **2.** $\cos x = \cos\frac{2\pi}{3}$ : $S = \left\{-\frac{2\pi}{3}\,;\,\frac{2\pi}{3}\right\}$.

    **3.** Arc au-dessus de la droite $y = \frac{\sqrt{3}}{2}$ : $S = \left[\frac{\pi}{3}\,;\,\frac{2\pi}{3}\right]$.

## Sujet 2

### Partie 1 — Automatismes (QCM)

**Question 1.** Pour tout réel $x$, $\cos(\pi - x)$ est égal à :

a. $\cos x$ ; b. $-\cos x$ ; c. $\sin x$ ; d. $-\sin x$.

**Question 2.** Pour tout réel $x$, $\sin(-x)$ est égal à :

a. $\sin x$ ; b. $-\sin x$ ; c. $\cos x$ ; d. $-\cos x$.

**Question 3.** $\cos\frac{5\pi}{6}$ est égal à :

a. $\frac{\sqrt{3}}{2}$ ; b. $-\frac{\sqrt{3}}{2}$ ; c. $\frac{1}{2}$ ; d. $-\frac{1}{2}$.

**Question 4.** La fonction cosinus est :

a. impaire ; b. paire ; c. ni paire ni impaire ; d. croissante sur $\mathbb{R}$.

**Question 5.** La solution de l'équation $3x + 5 = 2x - 1$ est :

a. $6$ ; b. $-6$ ; c. $4$ ; d. $-4$.

**Question 6.** Une veste coûte $80$ € après une remise de $20\,\%$. Son prix initial était :

a. $96$ € ; b. $100$ € ; c. $64$ € ; d. $90$ €.

### Partie 2 — Exercice

1. Simplifier, pour tout réel $x$ :
   $$A(x) = \cos(-x) + \cos(\pi - x) + \sin\left(\frac{\pi}{2} - x\right).$$
2. Simplifier $B(x) = \sin(\pi + x) - \sin(\pi - x) + 2\sin x$.
3. Résoudre dans $]-\pi\,;\,\pi]$ l'équation $\sin x = \frac{\sqrt{2}}{2}$.
4. Résoudre dans $]-\pi\,;\,\pi]$ l'équation $2\cos^2 x = 1$.
5. Résoudre dans $]-\pi\,;\,\pi]$ l'inéquation $\cos x > -\frac{\sqrt{2}}{2}$.

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **b.** $\cos\left(\pi - \frac{\pi}{6}\right)$. 4. **b.** 5. **b.** 6. **b.** $\frac{80}{0{,}8}$.

    **Partie 2**

    **1.** $A(x) = \cos x - \cos x + \cos x = \cos x$.

    **2.** $B(x) = -\sin x - \sin x + 2\sin x = 0$.

    **3.** $\sin x = \sin\frac{\pi}{4}$ : $x = \frac{\pi}{4}$ ou $x = \pi - \frac{\pi}{4} = \frac{3\pi}{4}$.

    **4.** $\cos^2 x = \frac{1}{2}$, donc $\cos x = \frac{\sqrt{2}}{2}$ ou $\cos x = -\frac{\sqrt{2}}{2}$. $S = \left\{-\frac{3\pi}{4}\,;\,-\frac{\pi}{4}\,;\,\frac{\pi}{4}\,;\,\frac{3\pi}{4}\right\}$.

    **5.** Arc à droite de la droite $x = -\frac{\sqrt{2}}{2}$ : $S = \left]-\frac{3\pi}{4}\,;\,\frac{3\pi}{4}\right[$.

## Sujet 3

### Partie 1 — Automatismes (QCM)

**Question 1.** Si $\cos x = 0{,}6$, alors $\sin^2 x$ vaut :

a. $0{,}4$ ; b. $0{,}64$ ; c. $0{,}36$ ; d. $0{,}8$.

**Question 2.** Sur l'intervalle $]-\pi\,;\,0[$, le sinus est :

a. positif ; b. négatif ; c. nul ; d. de signe variable.

**Question 3.** $\sqrt{\dfrac{16}{25}}$ est égal à :

a. $\frac{4}{25}$ ; b. $\frac{4}{5}$ ; c. $\frac{16}{5}$ ; d. $\frac{2}{5}$.

**Question 4.** Pour tout réel $x$, $\cos\left(\frac{\pi}{2} - x\right)$ est égal à :

a. $\cos x$ ; b. $-\sin x$ ; c. $\sin x$ ; d. $-\cos x$.

**Question 5.** $\dfrac{5}{6} - \dfrac{1}{4}$ est égal à :

a. $\frac{4}{2}$ ; b. $\frac{7}{12}$ ; c. $\frac{1}{3}$ ; d. $\frac{4}{24}$.

**Question 6.** La probabilité d'obtenir un nombre pair avec un dé équilibré à six faces est :

a. $\frac{1}{6}$ ; b. $\frac{1}{3}$ ; c. $\frac{1}{2}$ ; d. $\frac{2}{3}$.

### Partie 2 — Exercice

Soit $x$ un réel de l'intervalle $\left]-\pi\,;\,-\frac{\pi}{2}\right[$ tel que $\cos x = -\frac{3}{5}$.

1. Dans quel quadrant se trouve le point $M(x)$ ? Quel est le signe de $\sin x$ ?
2. Calculer $\sin x$.
3. En déduire : $\cos(-x)$, $\sin(\pi - x)$, $\cos(\pi + x)$, $\sin\left(\frac{\pi}{2} - x\right)$.
4. Soit $y = x + 2\pi$. Calculer $\cos y$ et $\sin y$. Dans quel intervalle se trouve $y$ ?
5. Montrer que $(\cos x + \sin x)^2 = 1 + 2\cos x\sin x$, puis calculer cette quantité.

??? success "Correction"
    **Partie 1**

    1. **b.** $1 - 0{,}36$. 2. **b.** 3. **b.** 4. **c.** 5. **b.** $\frac{10}{12} - \frac{3}{12}$. 6. **c.**

    **Partie 2**

    **1.** En bas à gauche (troisième quadrant) : $\sin x < 0$.

    **2.** $\sin^2 x = 1 - \frac{9}{25} = \frac{16}{25}$, donc $\sin x = -\frac{4}{5}$.

    **3.** $\cos(-x) = -\frac{3}{5}$ ; $\sin(\pi - x) = \sin x = -\frac{4}{5}$ ; $\cos(\pi + x) = -\cos x = \frac{3}{5}$ ; $\sin\left(\frac{\pi}{2} - x\right) = \cos x = -\frac{3}{5}$.

    **4.** $\cos y = -\frac{3}{5}$ et $\sin y = -\frac{4}{5}$ (même point du cercle). $y \in \left]\pi\,;\,\frac{3\pi}{2}\right[$.

    **5.** $(\cos x + \sin x)^2 = \cos^2 x + \sin^2 x + 2\cos x\sin x = 1 + 2\cos x\sin x$. Ici : $1 + 2 \times \left(-\frac{3}{5}\right) \times \left(-\frac{4}{5}\right) = 1 + \frac{24}{25} = \frac{49}{25}$. *Vérification : $\cos x + \sin x = -\frac{7}{5}$, dont le carré vaut bien $\frac{49}{25}$.*

## Sujet 4

### Partie 1 — Automatismes (QCM)

**Question 1.** Les fonctions cosinus et sinus sont périodiques de période :

a. $\pi$ ; b. $2\pi$ ; c. $\frac{\pi}{2}$ ; d. $360$.

**Question 2.** L'équation $\cos x = 2$ :

a. a une solution ; b. a deux solutions dans $]-\pi\,;\,\pi]$ ; c. n'a pas de solution ; d. a une infinité de solutions.

**Question 3.** Les racines de $2X^2 + X - 1$ sont :

a. $1$ et $-\frac{1}{2}$ ; b. $-1$ et $\frac{1}{2}$ ; c. $1$ et $\frac{1}{2}$ ; d. $-1$ et $-\frac{1}{2}$.

**Question 4.** $\sin\frac{3\pi}{2}$ est égal à :

a. $1$ ; b. $-1$ ; c. $0$ ; d. $\frac{1}{2}$.

**Question 5.** La dérivée de $x \mapsto x^3 - 2x$ est :

a. $3x^2 - 2$ ; b. $3x^2$ ; c. $x^2 - 2$ ; d. $3x - 2$.

**Question 6.** $25\,\%$ de $25\,\%$ correspond à :

a. $50\,\%$ ; b. $6{,}25\,\%$ ; c. $0{,}625\,\%$ ; d. $12{,}5\,\%$.

### Partie 2 — Exercice

Pour tout réel $x$, on pose $f(x) = 2\cos^2 x + \cos x - 1$.

1. Calculer $f(0)$, $f\left(\frac{\pi}{2}\right)$ et $f(\pi)$.
2. Montrer que $f$ est paire et que $f(x + 2\pi) = f(x)$. Pourquoi suffit-il d'étudier $f$ sur $[0\,;\,\pi]$ ?
3. a. Factoriser $2X^2 + X - 1$.
   b. En déduire que $f(x) = (2\cos x - 1)(\cos x + 1)$.
4. Résoudre l'équation $f(x) = 0$ dans $[0\,;\,\pi]$.
5. Étudier le signe de $f(x)$ sur $[0\,;\,\pi]$. *On remarquera que $\cos x + 1 \geq 0$.*

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **c.** $-1 \leq \cos x \leq 1$. 3. **b.** Somme $-\frac{1}{2}$, produit $-\frac{1}{2}$. 4. **b.** 5. **a.** 6. **b.** $0{,}25^2 = 0{,}0625$.

    **Partie 2**

    **1.** $f(0) = 2 + 1 - 1 = 2$ ; $f\left(\frac{\pi}{2}\right) = -1$ ; $f(\pi) = 2 - 1 - 1 = 0$.

    **2.** $\cos(-x) = \cos x$, donc $f(-x) = f(x)$. Et $\cos(x + 2\pi) = \cos x$. Grâce à la période $2\pi$, il suffit d'étudier $f$ sur un intervalle de longueur $2\pi$, par exemple $[-\pi\,;\,\pi]$ ; grâce à la parité, il suffit ensuite de l'étudier sur $[0\,;\,\pi]$ et de compléter par symétrie.

    **3. a.** Racines $\frac{1}{2}$ et $-1$ : $2X^2 + X - 1 = 2\left(X - \frac{1}{2}\right)(X + 1) = (2X - 1)(X + 1)$.

    **b.** On remplace $X$ par $\cos x$.

    **4.** $f(x) = 0 \iff \cos x = \frac{1}{2}$ ou $\cos x = -1$. Dans $[0\,;\,\pi]$ : $x = \frac{\pi}{3}$ ou $x = \pi$.

    **5.** Sur $[0\,;\,\pi[$, $\cos x + 1 > 0$ : $f(x)$ a le signe de $2\cos x - 1$. Or $\cos x > \frac{1}{2} \iff x \in \left[0\,;\,\frac{\pi}{3}\right[$ (sur $[0\,;\,\pi]$, le cosinus décroît). Donc $f(x) > 0$ sur $\left[0\,;\,\frac{\pi}{3}\right[$, $f(x) < 0$ sur $\left]\frac{\pi}{3}\,;\,\pi\right[$, et $f$ s'annule en $\frac{\pi}{3}$ et $\pi$.
