# Automatismes pour l'épreuve anticipée

La **première partie** de l'épreuve anticipée de mathématiques (6 points sur 20) est un **QCM d'automatismes**, à faire **sans calculatrice**. Ces questions portent sur des savoir-faire de collège, de Seconde et de Première qui doivent devenir des réflexes. Cette page rassemble les **règles à connaître** et **deux séries d'entraînement** corrigées. Chaque chapitre propose aussi six questions d'automatismes dans ses [sujets type](../index.md).

---

## 1. Calcul numérique

| À savoir | Exemple |
|---|---|
| $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$ (ou réduire au même dénominateur) | $\frac{2}{3} + \frac{1}{4} = \frac{8 + 3}{12} = \frac{11}{12}$ |
| $\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$ ; diviser, c'est multiplier par l'inverse | $\frac{3}{4} \div \frac{9}{2} = \frac{3}{4} \times \frac{2}{9} = \frac{1}{6}$ |
| $a^m \times a^n = a^{m+n}$, $\frac{a^m}{a^n} = a^{m-n}$, $(a^m)^n = a^{mn}$, $a^{-n} = \frac{1}{a^n}$ | $\frac{10^5 \times 10^{-2}}{10^4} = 10^{-1}$ |
| $\sqrt{ab} = \sqrt{a}\sqrt{b}$ ; $\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}$ | $\sqrt{50} = 5\sqrt{2}$ |
| Écriture scientifique $a \times 10^n$ avec $1 \leq a < 10$ | $0{,}00042 = 4{,}2 \times 10^{-4}$ |

## 2. Calcul littéral

- **Identités remarquables** : $(a + b)^2 = a^2 + 2ab + b^2$ ; $(a - b)^2 = a^2 - 2ab + b^2$ ; $(a + b)(a - b) = a^2 - b^2$.
- **Factoriser** : chercher un facteur commun, ou reconnaître une identité. $x^2 - 9 = (x - 3)(x + 3)$ ; $3x^2 - 6x = 3x(x - 2)$.
- **Équation produit nul** : $AB = 0 \iff A = 0$ ou $B = 0$.
- **Inéquation** : multiplier ou diviser par un nombre **négatif** change le sens. $-2x > 6 \iff x < -3$.
- **Isoler une variable** dans une formule : $v = \frac{d}{t} \iff t = \frac{d}{v}$.

## 3. Proportions et pourcentages

| À savoir | Exemple |
|---|---|
| Prendre $t\,\%$ de $A$ : $\frac{t}{100} \times A$ | $15\,\%$ de $80$ : $12$ |
| Proportion de proportion : on multiplie | $30\,\%$ de $40\,\%$ : $0{,}3 \times 0{,}4 = 0{,}12$, soit $12\,\%$ |
| Augmenter de $t\,\%$ : multiplier par $1 + \frac{t}{100}$ | $+20\,\%$ : $\times 1{,}2$ |
| Diminuer de $t\,\%$ : multiplier par $1 - \frac{t}{100}$ | $-15\,\%$ : $\times 0{,}85$ |
| Taux d'évolution : $\frac{V_A - V_D}{V_D}$ | de $50$ à $60$ : $+20\,\%$ |
| Évolutions successives : on **multiplie** les coefficients | $+10\,\%$ puis $+10\,\%$ : $\times 1{,}21$, soit $+21\,\%$ |
| Évolution réciproque : coefficient $\frac{1}{CM}$ | après $-20\,\%$, il faut $\times 1{,}25$ ($+25\,\%$) pour revenir |

## 4. Fonctions et graphiques

- **Image** de $a$ : $f(a)$, lue sur l'axe des ordonnées ; **antécédent(s)** de $b$ : les $x$ tels que $f(x) = b$.
- **Droite** $y = mx + p$ : $p$ est l'ordonnée à l'origine ; $m = \frac{y_B - y_A}{x_B - x_A}$ ; $m > 0$ : fonction croissante.
- **Signe** d'une fonction : $f(x) > 0$ quand la courbe est **au-dessus** de l'axe des abscisses.
- **Nombre dérivé** $f'(a)$ : coefficient directeur de la tangente au point d'abscisse $a$.
- **Second degré** : sommet en $x = -\frac{b}{2a}$ ; $\Delta = b^2 - 4ac$.

## 5. Statistiques et probabilités

- **Moyenne** : $\bar{x} = \frac{\text{somme des valeurs}}{\text{effectif}}$ ; moyenne pondérée $\frac{\sum n_ix_i}{\sum n_i}$.
- **Médiane** : valeur qui partage la série **ordonnée** en deux moitiés.
- **Équiprobabilité** : $P(A) = \frac{\text{issues favorables}}{\text{issues possibles}}$ ; $P\left(\overline{A}\right) = 1 - P(A)$.
- **Arbre** : on multiplie le long d'un chemin, on additionne les chemins.

## 6. Série d'entraînement n° 1

**Sans calculatrice, 20 minutes.** Pour chaque question, une seule réponse est exacte.

**1.** $\dfrac{5}{6} - \dfrac{3}{4}$ est égal à : a. $\frac{1}{12}$ ; b. $\frac{2}{2}$ ; c. $\frac{1}{6}$ ; d. $\frac{2}{10}$.

**2.** $\dfrac{2^5 \times 2^{-3}}{2^4}$ est égal à : a. $2^{-2}$ ; b. $2^{6}$ ; c. $2^{2}$ ; d. $2^{-12}$.

**3.** $\sqrt{72}$ est égal à : a. $8\sqrt{9}$ ; b. $6\sqrt{2}$ ; c. $36\sqrt{2}$ ; d. $2\sqrt{6}$.

**4.** La forme développée de $(3x - 2)^2$ est : a. $9x^2 - 4$ ; b. $9x^2 - 6x + 4$ ; c. $9x^2 - 12x + 4$ ; d. $3x^2 - 12x + 4$.

**5.** Les solutions de $(x - 1)(2x + 6) = 0$ sont : a. $1$ et $3$ ; b. $-1$ et $3$ ; c. $1$ et $-3$ ; d. $1$ et $-6$.

**6.** Un prix passe de $80$ € à $92$ €. Le taux d'évolution est : a. $+12\,\%$ ; b. $+15\,\%$ ; c. $+13\,\%$ ; d. $+1{,}15\,\%$.

**7.** Une baisse de $20\,\%$ suivie d'une hausse de $20\,\%$ correspond à : a. aucune évolution ; b. une baisse de $4\,\%$ ; c. une hausse de $4\,\%$ ; d. une baisse de $2\,\%$.

**8.** La droite passant par $(1\,;\,3)$ et $(3\,;\,-1)$ a pour coefficient directeur : a. $2$ ; b. $-2$ ; c. $-\frac{1}{2}$ ; d. $1$.

**9.** L'inéquation $5 - 3x \leq 11$ a pour solutions : a. $x \leq -2$ ; b. $x \geq -2$ ; c. $x \geq 2$ ; d. $x \leq 2$.

**10.** La moyenne de la série $8 \,;\, 12 \,;\, 12 \,;\, 16 \,;\, 2$ est : a. $12$ ; b. $10$ ; c. $9$ ; d. $50$.

**11.** On tire une carte dans un jeu de $32$ cartes. La probabilité d'obtenir une figure (valet, dame, roi) est : a. $\frac{3}{32}$ ; b. $\frac{1}{4}$ ; c. $\frac{3}{8}$ ; d. $\frac{12}{52}$.

**12.** $0{,}00035$ s'écrit en notation scientifique : a. $35 \times 10^{-5}$ ; b. $3{,}5 \times 10^{-4}$ ; c. $3{,}5 \times 10^{4}$ ; d. $0{,}35 \times 10^{-3}$.

??? success "Correction de la série n° 1"
    1. **a.** $\frac{10}{12} - \frac{9}{12}$. 2. **a.** $2^{5 - 3 - 4}$. 3. **b.** $\sqrt{36 \times 2}$. 4. **c.** 5. **c.** 6. **b.** $\frac{12}{80} = 0{,}15$. 7. **b.** $0{,}8 \times 1{,}2 = 0{,}96$. 8. **b.** $\frac{-1 - 3}{3 - 1}$. 9. **b.** $-3x \leq 6$, on divise par $-3$. 10. **b.** $\frac{50}{5}$. 11. **c.** $\frac{12}{32}$. 12. **b.**

## 7. Série d'entraînement n° 2

**Sans calculatrice, 20 minutes.**

**1.** $\dfrac{4}{9} \div \dfrac{2}{3}$ est égal à : a. $\frac{8}{27}$ ; b. $\frac{2}{3}$ ; c. $\frac{3}{2}$ ; d. $\frac{6}{9}$.

**2.** $(\sqrt{5} - 1)(\sqrt{5} + 1)$ est égal à : a. $4$ ; b. $6$ ; c. $5$ ; d. $24$.

**3.** La factorisation de $4x^2 - 25$ est : a. $(4x - 5)(4x + 5)$ ; b. $(2x - 5)^2$ ; c. $(2x - 5)(2x + 5)$ ; d. $4(x - 5)(x + 5)$.

**4.** Si $P = 2(L + \ell)$, alors $\ell$ est égal à : a. $\frac{P}{2} - L$ ; b. $P - 2L$ ; c. $\frac{P - L}{2}$ ; d. $2P - L$.

**5.** $40\,\%$ des élèves d'un lycée sont en Seconde, et $25\,\%$ d'entre eux sont demi-pensionnaires. La proportion d'élèves du lycée en Seconde demi-pensionnaires est : a. $65\,\%$ ; b. $15\,\%$ ; c. $10\,\%$ ; d. $1\,\%$.

**6.** Un article soldé à $-25\,\%$ coûte $60$ €. Son prix avant soldes était : a. $75$ € ; b. $80$ € ; c. $85$ € ; d. $45$ €.

**7.** $f(x) = -x^2 + 6x - 1$ atteint son maximum en : a. $x = -3$ ; b. $x = 6$ ; c. $x = 3$ ; d. $x = 8$.

**8.** Le discriminant de $2x^2 - 3x + 1$ vaut : a. $1$ ; b. $17$ ; c. $-1$ ; d. $9$.

**9.** La dérivée de $f(x) = 3x^2 - 5x + 2$ est : a. $6x - 5$ ; b. $3x - 5$ ; c. $6x + 2$ ; d. $6x^2 - 5$.

**10.** La médiane de la série $3 \,;\, 9 \,;\, 4 \,;\, 1 \,;\, 7 \,;\, 6$ est : a. $4$ ; b. $5$ ; c. $6$ ; d. $5{,}5$.

**11.** Si $P(A) = 0{,}35$, alors $P\left(\overline{A}\right)$ vaut : a. $0{,}35$ ; b. $0{,}75$ ; c. $0{,}65$ ; d. $1{,}35$.

**12.** Une vitesse de $90$ km/h correspond à : a. $15$ m/s ; b. $25$ m/s ; c. $30$ m/s ; d. $324$ m/s.
