## Évaluation 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** $\sqrt{18}$ est égal à :

a. $9\sqrt{2}$ ; b. $3\sqrt{2}$ ; c. $2\sqrt{3}$ ; d. $6$.

**Question 2.** $\left(\sqrt{7}\right)^2$ est égal à :

a. $49$ ; b. $\sqrt{14}$ ; c. $7$ ; d. $14$.

**Question 3.** $\dfrac{1}{2} + \dfrac{2}{5}$ est égal à :

a. $\frac{3}{7}$ ; b. $\frac{9}{10}$ ; c. $\frac{3}{10}$ ; d. $\frac{1}{5}$.

**Question 4.** $(x + 3)^2$ est égal à :

a. $x^2 + 9$ ; b. $x^2 + 3x + 9$ ; c. $x^2 + 6x + 9$ ; d. $x^2 + 6x + 6$.

**Question 5.** Un article à $40$ € augmente de $15\,\%$. Il coûte :

a. $55$ € ; b. $46$ € ; c. $41{,}50$ € ; d. $34$ €.

**Question 6.** Dans un triangle rectangle, l'hypoténuse mesure $10$ et un angle aigu mesure $30°$. Le côté opposé à cet angle mesure :

a. $5$ ; b. $5\sqrt{3}$ ; c. $10\sqrt{3}$ ; d. $20$.

### Partie 2 — Exercice

**A. Question de cours.** Démontrer que pour tous réels positifs $a$ et $b$, $\sqrt{ab} = \sqrt{a} \times \sqrt{b}$.

**B. Application.**

1. Écrire sous la forme $a\sqrt{3}$ : $A = \sqrt{48} - 2\sqrt{75} + \sqrt{27}$.
2. Développer et réduire $B = \left(1 + 2\sqrt{3}\right)^2$ et $C = \left(\sqrt{6} - \sqrt{2}\right)\left(\sqrt{6} + \sqrt{2}\right)$.
3. Écrire $D = \dfrac{4}{\sqrt{6} - \sqrt{2}}$ sans racine au dénominateur.
4. Un carré a pour aire $72$ cm². Donner la valeur exacte de son côté, puis de sa diagonale.

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **c.** 3. **b.** 4. **c.** 5. **b.** $40 \times 1{,}15$. 6. **a.** $10 \times \sin 30°$.

    **Partie 2**

    **A.** $\sqrt{a} \times \sqrt{b} \geq 0$ et $\left(\sqrt{a}\sqrt{b}\right)^2 = ab$ : c'est le réel positif dont le carré est $ab$, donc c'est $\sqrt{ab}$.

    **B. 1.** $A = 4\sqrt{3} - 10\sqrt{3} + 3\sqrt{3} = -3\sqrt{3}$.

    **2.** $B = 1 + 4\sqrt{3} + 12 = 13 + 4\sqrt{3}$ ; $C = 6 - 2 = 4$.

    **3.** $D = \dfrac{4\left(\sqrt{6} + \sqrt{2}\right)}{6 - 2} = \sqrt{6} + \sqrt{2}$.

    **4.** Côté $\sqrt{72} = 6\sqrt{2}$ cm ; diagonale $6\sqrt{2} \times \sqrt{2} = 12$ cm.

## Évaluation 2

### Partie 1 — Automatismes (QCM)

**Question 1.** $2^{-3}$ est égal à :

a. $-8$ ; b. $-6$ ; c. $\frac{1}{8}$ ; d. $\frac{1}{6}$.

**Question 2.** $\dfrac{10^{4} \times 10^{-7}}{10^{-2}}$ est égal à :

a. $10^{-1}$ ; b. $10^{-5}$ ; c. $10^{1}$ ; d. $10^{13}$.

**Question 3.** $(-3)^4$ est égal à :

a. $-81$ ; b. $81$ ; c. $-12$ ; d. $12$.

**Question 4.** L'écriture scientifique de $0{,}0045$ est :

a. $45 \times 10^{-4}$ ; b. $4{,}5 \times 10^{3}$ ; c. $4{,}5 \times 10^{-3}$ ; d. $0{,}45 \times 10^{-2}$.

**Question 5.** $1$ km² est égal à :

a. $1\,000$ m² ; b. $100\,000$ m² ; c. $1\,000\,000$ m² ; d. $10\,000$ m².

**Question 6.** La moitié de $2^{10}$ est :

a. $2^{5}$ ; b. $1^{10}$ ; c. $2^{9}$ ; d. $2^{11}$.

### Partie 2 — Exercice

1. Écrire sous la forme $2^m \times 3^n$ : $A = \dfrac{12^3 \times 9^{-1}}{8 \times 6^{2}}$.
2. Calculer $B = \dfrac{3 \times 10^{-2} \times 8 \times 10^{5}}{1{,}2 \times 10^{-3}}$ et donner le résultat en écriture scientifique.
3. Le cerveau humain contient environ $8{,}6 \times 10^{10}$ neurones, et la population mondiale est d'environ $8 \times 10^{9}$ personnes. Combien y a-t-il de neurones, au total, dans tous les cerveaux humains ? Donner un ordre de grandeur.
4. Une feuille de papier a une épaisseur de $0{,}1$ mm. On la plie en deux $10$ fois de suite. Sachant que $2^{10} = 1\,024$, quelle est l'épaisseur obtenue ? Et après $40$ pliages (en admettant que ce soit possible), sachant que $2^{40} \approx 1{,}1 \times 10^{12}$ ?

??? success "Correction"
    **Partie 1**

    1. **c.** 2. **a.** $10^{4 - 7 + 2}$. 3. **b.** 4. **c.** 5. **c.** 6. **c.** $\frac{2^{10}}{2}$.

    **Partie 2**

    **1.** $12^3 = 2^6 \times 3^3$, $9^{-1} = 3^{-2}$, $8 = 2^3$, $6^2 = 2^2 \times 3^2$. Donc $A = \dfrac{2^6 \times 3}{2^5 \times 3^2} = 2 \times 3^{-1}$.

    **2.** $B = \frac{3 \times 8}{1{,}2} \times 10^{-2 + 5 + 3} = 20 \times 10^{6} = 2 \times 10^{7}$.

    **3.** $8{,}6 \times 8 \times 10^{19} \approx 69 \times 10^{19} \approx 6{,}9 \times 10^{20}$ : de l'ordre de $10^{21}$ neurones.

    **4.** $0{,}1 \times 1\,024 = 102{,}4$ mm, soit environ $10$ cm. Après $40$ pliages : $0{,}1 \times 1{,}1 \times 10^{12} = 1{,}1 \times 10^{11}$ mm $= 1{,}1 \times 10^{8}$ m, soit $110\,000$ km, plus d'un quart de la distance Terre-Lune !

## Évaluation 3

### Partie 1 — Automatismes (QCM)

**Question 1.** La forme factorisée de $x^2 - 16$ est :

a. $(x - 4)^2$ ; b. $(x - 8)(x + 8)$ ; c. $(x - 4)(x + 4)$ ; d. $(x - 16)(x + 1)$.

**Question 2.** Le développement de $-(x - 2)(x + 3)$ est :

a. $-x^2 - x + 6$ ; b. $-x^2 + x - 6$ ; c. $-x^2 - x - 6$ ; d. $x^2 + x - 6$.

**Question 3.** $3x(x - 1) - (x - 1)$ est égal à :

a. $3x(x - 1)$ ; b. $(x - 1)(3x - 1)$ ; c. $(x - 1)(3x + 1)$ ; d. $2x(x - 1)$.

**Question 4.** $(2x - 5)^2$ est égal à :

a. $4x^2 - 25$ ; b. $4x^2 - 10x + 25$ ; c. $4x^2 - 20x + 25$ ; d. $2x^2 - 20x + 25$.

**Question 5.** Les solutions de $x(x + 2) = 0$ sont :

a. $0$ et $2$ ; b. $0$ et $-2$ ; c. $-2$ seulement ; d. $2$ seulement.

**Question 6.** La droite d'équation $y = 3x - 2$ coupe l'axe des ordonnées au point :

a. $(0\,;\,3)$ ; b. $(0\,;\,-2)$ ; c. $\left(\frac{2}{3}\,;\,0\right)$ ; d. $(-2\,;\,0)$.

### Partie 2 — Exercice

Soit $E(x) = (2x - 3)^2 - (x + 1)^2$.

1. Développer et réduire $E(x)$.
2. Factoriser $E(x)$.
3. En choisissant la forme la plus adaptée :  
    a. calculer $E(0)$ ;  
    b. calculer $E\left(\frac{3}{2}\right)$ ;  
    c. résoudre $E(x) = 0$ ;  
    d. résoudre $E(x) = 8$.

??? success "Correction"
    **Partie 1**

    1. **c.** 2. **a.** $-(x^2 + x - 6)$. 3. **b.** 4. **c.** 5. **b.** 6. **b.**

    **Partie 2**

    **1.** $E(x) = 4x^2 - 12x + 9 - (x^2 + 2x + 1) = 3x^2 - 14x + 8$.

    **2.** $E(x) = \big[(2x - 3) - (x + 1)\big]\big[(2x - 3) + (x + 1)\big] = (x - 4)(3x - 2)$.

    **3. a.** Forme développée : $E(0) = 8$.

    **b.** Forme de l'énoncé : $E\left(\frac{3}{2}\right) = 0 - \left(\frac{5}{2}\right)^2 = -\frac{25}{4}$.

    **c.** Forme factorisée : $x = 4$ ou $x = \frac{2}{3}$.

    **d.** Forme développée : $3x^2 - 14x + 8 = 8 \iff 3x^2 - 14x = 0 \iff x(3x - 14) = 0$, donc $x = 0$ ou $x = \frac{14}{3}$.

## Évaluation 4

### Partie 1 — Automatismes (QCM)

**Question 1.** Si $x < 5$, alors $-2x$ est :

a. inférieur à $-10$ ; b. supérieur à $-10$ ; c. inférieur à $10$ ; d. supérieur à $10$.

**Question 2.** Le plus grand des nombres $0{,}5$ ; $0{,}5^2$ ; $\sqrt{0{,}5}$ est :

a. $0{,}5$ ; b. $0{,}5^2$ ; c. $\sqrt{0{,}5}$ ; d. ils sont égaux.

**Question 3.** $\frac{5}{8} - \frac{3}{5}$ est :

a. positif ; b. négatif ; c. nul ; d. égal à $\frac{2}{3}$.

**Question 4.** Si $2 \leq x \leq 4$, alors $\frac{1}{x}$ est compris entre :

a. $2$ et $4$ ; b. $\frac{1}{2}$ et $\frac{1}{4}$, avec $\frac{1}{4} \leq \frac{1}{x} \leq \frac{1}{2}$ ; c. $-4$ et $-2$ ; d. $\frac{1}{2}$ et $4$.

**Question 5.** La formule $\mathcal{A} = \frac{bh}{2}$ donne $h = $ :

a. $2\mathcal{A}b$ ; b. $\frac{\mathcal{A}}{2b}$ ; c. $\frac{2\mathcal{A}}{b}$ ; d. $\frac{b}{2\mathcal{A}}$.

**Question 6.** Une boîte de $12$ œufs coûte $3{,}60$ €. Le prix d'un œuf est :

a. $0{,}03$ € ; b. $0{,}30$ € ; c. $0{,}36$ € ; d. $3$ €.

### Partie 2 — Exercice

1. Comparer $A = \dfrac{2\,025}{2\,026}$ et $B = \dfrac{2\,026}{2\,027}$ en calculant $B - A$.
2. Comparer $5\sqrt{2}$ et $2\sqrt{13}$.
3. On sait que $1 \leq x \leq 3$. Encadrer $4 - 2x$, puis $\dfrac{6}{x}$.
4. Démontrer que pour tout réel $x$, $x^2 + 4 \geq 4x$. Quand y a-t-il égalité ?
5. Démontrer que pour tout réel $x \geq 0$, $\dfrac{x}{1 + x} \leq x$.

??? success "Correction"
    **Partie 1**

    1. **b.** On multiplie par $-2 < 0$ : $-2x > -10$. 2. **c.** 3. **a.** $\frac{25 - 24}{40}$. 4. **b.** 5. **c.** 6. **b.**

    **Partie 2**

    **1.** $B - A = \dfrac{2\,026^2 - 2\,025 \times 2\,027}{2\,026 \times 2\,027}$. Or $2\,025 \times 2\,027 = (2\,026 - 1)(2\,026 + 1) = 2\,026^2 - 1$. Donc $B - A = \dfrac{1}{2\,026 \times 2\,027} > 0$ : $A < B$.

    **2.** $(5\sqrt{2})^2 = 50 < 52 = (2\sqrt{13})^2$ : $5\sqrt{2} < 2\sqrt{13}$.

    **3.** $2 \leq 2x \leq 6$, donc $-6 \leq -2x \leq -2$ et $-2 \leq 4 - 2x \leq 2$. Puis $\frac{1}{3} \leq \frac{1}{x} \leq 1$, donc $2 \leq \frac{6}{x} \leq 6$.

    **4.** $x^2 + 4 - 4x = (x - 2)^2 \geq 0$. Égalité si et seulement si $x = 2$.

    **5.** $x - \frac{x}{1 + x} = \frac{x(1 + x) - x}{1 + x} = \frac{x^2}{1 + x} \geq 0$ (car $1 + x > 0$).
