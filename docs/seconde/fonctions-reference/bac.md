## Évaluation 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** Les solutions de $x^2 = 49$ sont :

a. $7$ ; b. $-7$ et $7$ ; c. $24{,}5$ ; d. aucune.

**Question 2.** Si $-3 \leq x \leq 1$, alors :

a. $1 \leq x^2 \leq 9$ ; b. $0 \leq x^2 \leq 9$ ; c. $-9 \leq x^2 \leq 1$ ; d. $0 \leq x^2 \leq 1$.

**Question 3.** La fonction carré est :

a. croissante sur $\mathbb{R}$ ; b. paire ; c. impaire ; d. décroissante sur $[0\,;\,+\infty[$.

**Question 4.** $b^2 - a^2$ est égal à :

a. $(b - a)^2$ ; b. $(b - a)(b + a)$ ; c. $(a - b)(a + b)$ ; d. $b^2 + a^2 - 2ab$.

**Question 5.** $3{,}5 \times 4$ est égal à :

a. $12$ ; b. $14$ ; c. $12{,}20$ ; d. $16$.

**Question 6.** $\frac{1}{4} + \frac{1}{3}$ est égal à :

a. $\frac{2}{7}$ ; b. $\frac{7}{12}$ ; c. $\frac{1}{12}$ ; d. $\frac{1}{7}$.

### Partie 2 — Exercice

**A. Question de cours.** Démontrer que la fonction carré est croissante sur $[0\,;\,+\infty[$ et décroissante sur $]-\infty\,;\,0]$.

**B. Application.**

1. Sans calculatrice, comparer $(-1{,}5)^2$ et $(-1{,}4)^2$, puis $\left(\sqrt{3}\right)^2$ et $1{,}8^2$.
2. Encadrer $x^2$ lorsque $-4 \leq x \leq -2$, puis lorsque $-2 \leq x \leq 5$.
3. Résoudre $x^2 \leq 6$, puis $2x^2 - 1 > 7$.

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **b.** 4. **b.** 5. **b.** 6. **b.**

    **Partie 2**

    **A.** Pour $a < b$ : $b^2 - a^2 = (b - a)(b + a)$ avec $b - a > 0$. Si $0 \leq a < b$, $a + b > 0$ : la différence est positive, la fonction est croissante. Si $a < b \leq 0$, $a + b < 0$ : la différence est négative, la fonction est décroissante.

    **B. 1.** $-1{,}5 < -1{,}4 \leq 0$ et la fonction carré décroît sur $]-\infty\,;\,0]$ : $(-1{,}5)^2 > (-1{,}4)^2$. $\sqrt{3} \approx 1{,}73 < 1{,}8$, deux positifs : $\left(\sqrt{3}\right)^2 < 1{,}8^2$ (en effet $3 < 3{,}24$).

    **2.** $4 \leq x^2 \leq 16$ ; $0 \leq x^2 \leq 25$.

    **3.** $\left[-\sqrt{6}\,;\,\sqrt{6}\right]$ ; $x^2 > 4$ : $]-\infty\,;\,-2[ \cup ]2\,;\,+\infty[$.

## Évaluation 2

### Partie 1 — Automatismes (QCM)

**Question 1.** La fonction inverse est définie sur :

a. $\mathbb{R}$ ; b. $[0\,;\,+\infty[$ ; c. $\mathbb{R} \setminus \{0\}$ ; d. $]0\,;\,+\infty[$.

**Question 2.** Si $2 \leq x \leq 8$, alors $\frac{1}{x}$ est compris entre :

a. $2$ et $8$ ; b. $\frac{1}{8}$ et $\frac{1}{2}$ ; c. $-8$ et $-2$ ; d. $\frac{1}{2}$ et $8$.

**Question 3.** La solution de $\frac{1}{x} = -5$ est :

a. $5$ ; b. $-\frac{1}{5}$ ; c. $\frac{1}{5}$ ; d. aucune.

**Question 4.** $\frac{1}{b} - \frac{1}{a}$ est égal à :

a. $\frac{a - b}{ab}$ ; b. $\frac{b - a}{ab}$ ; c. $\frac{1}{b - a}$ ; d. $a - b$.

**Question 5.** $0{,}25$ est l'inverse de :

a. $2{,}5$ ; b. $4$ ; c. $-4$ ; d. $0{,}4$.

**Question 6.** Une quantité augmente de $5\,\%$ chaque année pendant deux ans. Elle est multipliée par :

a. $1{,}1$ ; b. $1{,}1025$ ; c. $1{,}05$ ; d. $0{,}9025$.

### Partie 2 — Exercice

**A. Question de cours.** Démontrer que la fonction inverse est décroissante sur $]0\,;\,+\infty[$.

**B. Application.**

1. Comparer $\frac{1}{\sqrt{2}}$ et $\frac{1}{1{,}5}$.
2. Résoudre $\frac{1}{x} \leq \frac{1}{4}$ sur $]0\,;\,+\infty[$, puis sur $\mathbb{R}^*$.
3. Un réservoir de $1\,000$ L est vidé par un débit constant $d$ (en L/min). La durée de vidange est $T(d) = \frac{1\,000}{d}$. Quel débit faut-il pour que la vidange dure au plus $20$ min ?

??? success "Correction"
    **Partie 1**

    1. **c.** 2. **b.** 3. **b.** 4. **a.** 5. **b.** 6. **b.**

    **Partie 2**

    **A.** Pour $0 < a < b$ : $\frac{1}{b} - \frac{1}{a} = \frac{a - b}{ab}$, avec $a - b < 0$ et $ab > 0$ : la différence est négative, donc $\frac{1}{b} < \frac{1}{a}$.

    **B. 1.** $\sqrt{2} \approx 1{,}41 < 1{,}5$, positifs : $\frac{1}{\sqrt{2}} > \frac{1}{1{,}5}$.

    **2.** Sur $]0\,;\,+\infty[$ : $x \geq 4$. Sur $]-\infty\,;\,0[$, $\frac{1}{x} < 0 \leq \frac{1}{4}$ : toujours vrai. $S = ]-\infty\,;\,0[ \cup [4\,;\,+\infty[$.

    **3.** $\frac{1\,000}{d} \leq 20 \iff \frac{1}{d} \leq \frac{1}{50} \iff d \geq 50$ L/min.

## Évaluation 3

### Partie 1 — Automatismes (QCM)

**Question 1.** La fonction racine carrée est définie sur :

a. $\mathbb{R}$ ; b. $[0\,;\,+\infty[$ ; c. $]0\,;\,+\infty[$ ; d. $\mathbb{R}^*$.

**Question 2.** Si $x^3 = -8$, alors $x$ vaut :

a. $2$ ; b. $-2$ ; c. $\pm 2$ ; d. pas de solution.

**Question 3.** $|{-7}| + |3|$ est égal à :

a. $-4$ ; b. $4$ ; c. $10$ ; d. $-10$.

**Question 4.** Si $0 < x < 1$, alors :

a. $x^2 > x$ ; b. $x^2 < x$ ; c. $\sqrt{x} < x$ ; d. $x^3 > x^2$.

**Question 5.** $\sqrt{0{,}49}$ est égal à :

a. $0{,}7$ ; b. $0{,}07$ ; c. $0{,}245$ ; d. $7$.

**Question 6.** $2^{10}$ vaut environ :

a. $100$ ; b. $1\,000$ ; c. $10\,000$ ; d. $20$.

### Partie 2 — Exercice

On sait que $1 \leq x \leq 9$.

1. Encadrer $\sqrt{x}$, $x^2$, $\frac{1}{x}$ et $x^3$.
2. Encadrer $A = 3 - \frac{2}{x}$.
3. Encadrer $B = \sqrt{x} + x^2$.
4. Comparer $\sqrt{x}$ et $x$ pour $x \in [1\,;\,9]$.
5. Résoudre dans $\mathbb{R}$ : $|x - 5| \leq 4$. Que remarque-t-on ?

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **c.** 4. **b.** 5. **a.** 6. **b.** ($1\,024$)

    **Partie 2**

    **1.** $1 \leq \sqrt{x} \leq 3$ ; $1 \leq x^2 \leq 81$ ; $\frac{1}{9} \leq \frac{1}{x} \leq 1$ ; $1 \leq x^3 \leq 729$.

    **2.** $\frac{2}{9} \leq \frac{2}{x} \leq 2$, donc $-2 \leq -\frac{2}{x} \leq -\frac{2}{9}$ et $1 \leq A \leq \frac{25}{9}$.

    **3.** On additionne les encadrements : $2 \leq B \leq 84$.

    **4.** Pour $x \geq 1$, $\sqrt{x} \leq x$ (positions relatives).

    **5.** Distance de $x$ à $5$ au plus $4$ : $x \in [1\,;\,9]$. C'est exactement l'intervalle de l'énoncé : $1 \leq x \leq 9 \iff |x - 5| \leq 4$.

## Évaluation 4

### Partie 1 — Automatismes (QCM)

**Question 1.** Les courbes de $x \mapsto x^2$ et $x \mapsto x$ se coupent aux points d'abscisses :

a. $0$ et $1$ ; b. $1$ seulement ; c. $-1$ et $1$ ; d. $0$ seulement.

**Question 2.** La courbe de la fonction inverse est symétrique par rapport :

a. à l'axe des abscisses ; b. à l'axe des ordonnées ; c. à l'origine ; d. à la droite $y = x$ seulement.

**Question 3.** $x^2 - 2x - 8$ est égal à :

a. $(x - 4)(x + 2)$ ; b. $(x + 4)(x - 2)$ ; c. $(x - 8)(x + 1)$ ; d. $(x - 2)^2 - 4$.

**Question 4.** Le point $(4\,;\,2)$ est sur la courbe de :

a. $x \mapsto x^2$ ; b. $x \mapsto \sqrt{x}$ ; c. $x \mapsto \frac{1}{x}$ ; d. $x \mapsto x^3$.

**Question 5.** Un article coûte $80$ € TTC, TVA de $20\,\%$ incluse. Son prix hors taxes est :

a. $64$ € ; b. $66{,}67$ € ; c. $60$ € ; d. $96$ €.

**Question 6.** La médiane de $2 \,;\, 3 \,;\, 3 \,;\, 8 \,;\, 10 \,;\, 12$ est :

a. $3$ ; b. $5{,}5$ ; c. $6{,}3$ ; d. $8$.

### Partie 2 — Exercice

On considère $f(x) = x^2$ et $g(x) = 2x + 8$.

1. Tracer les courbes de $f$ et $g$ pour $x \in [-3\,;\,5]$.
2. Résoudre graphiquement $f(x) = g(x)$, puis $f(x) < g(x)$.
3. Vérifier que $x^2 - 2x - 8 = (x - 4)(x + 2)$, et retrouver les résultats par le calcul.
4. Soit $h(x) = \frac{8}{x}$ pour $x > 0$. Résoudre $f(x) = h(x)$ puis $f(x) > h(x)$ sur $]0\,;\,+\infty[$.

??? success "Correction"
    **Partie 1**

    1. **a.** 2. **c.** 3. **a.** 4. **b.** 5. **b.** $\frac{80}{1{,}2} \approx 66{,}67$. 6. **b.** $\frac{3 + 8}{2}$.

    **Partie 2**

    **2.** Intersections en $x = -2$ et $x = 4$ ; la parabole est sous la droite entre les deux : $]-2\,;\,4[$.

    **3.** $(x - 4)(x + 2) = x^2 - 2x - 8$. ✓ $f(x) < g(x) \iff (x - 4)(x + 2) < 0 \iff x \in ]-2\,;\,4[$.

    **4.** $x^2 = \frac{8}{x} \iff x^3 = 8 \iff x = 2$. Pour $x > 0$ : $x^2 > \frac{8}{x} \iff x^3 > 8 \iff x > 2$ (fonction cube croissante). $S = ]2\,;\,+\infty[$.
