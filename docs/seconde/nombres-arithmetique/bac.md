## Évaluation 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** $\dfrac{2}{3} + \dfrac{1}{6}$ est égal à :

a. $\frac{3}{9}$ ; b. $\frac{5}{6}$ ; c. $\frac{1}{2}$ ; d. $\frac{3}{6}$.

**Question 2.** Le nombre $\frac{14}{35}$ est égal à :

a. $0{,}4$ ; b. $0{,}04$ ; c. $\frac{1}{2}$ ; d. $0{,}35$.

**Question 3.** $10^3 \times 10^{-5}$ est égal à :

a. $10^{-15}$ ; b. $10^{2}$ ; c. $10^{-2}$ ; d. $10^{8}$.

**Question 4.** Le plus petit ensemble contenant $\sqrt{36}$ est :

a. $\mathbb{N}$ ; b. $\mathbb{Z}$ ; c. $\mathbb{Q}$ ; d. $\mathbb{R}$.

**Question 5.** $20\,\%$ de $45$ est égal à :

a. $9$ ; b. $20$ ; c. $4{,}5$ ; d. $25$.

**Question 6.** Un triangle rectangle a des côtés de l'angle droit de longueurs $5$ et $12$. Son hypoténuse mesure :

a. $17$ ; b. $13$ ; c. $\sqrt{119}$ ; d. $169$.

### Partie 2 — Exercice

**A. Question de cours.**

1. Démontrer que le carré d'un nombre impair est impair. En déduire que si $n^2$ est pair, alors $n$ est pair.
2. Démontrer que $\sqrt{2}$ est irrationnel.

**B. Application.**

1. Démontrer que $\sqrt{8}$ est irrationnel. *(On pourra simplifier $\sqrt{8}$.)*
2. Le nombre $\left(\sqrt{2} - 1\right)\left(\sqrt{2} + 1\right)$ est-il rationnel ?
3. Encadrer $\sqrt{2}$ à $10^{-1}$ près, en justifiant par un calcul de carrés.

??? success "Correction"
    **Partie 1**

    1. **b.** $\frac{4}{6} + \frac{1}{6}$. 2. **a.** $\frac{2}{5}$. 3. **c.** 4. **a.** $\sqrt{36} = 6$. 5. **a.** 6. **b.** $\sqrt{25 + 144} = \sqrt{169}$.

    **Partie 2**

    **A. 1.** Si $n = 2k + 1$, $n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$, impair. Par contraposée : si $n^2$ est pair, $n$ ne peut pas être impair, donc il est pair.

    **2.** Par l'absurde, $\sqrt{2} = \frac{p}{q}$ irréductible. Alors $p^2 = 2q^2$ est pair, donc $p$ est pair : $p = 2k$. Alors $4k^2 = 2q^2$, $q^2 = 2k^2$ est pair, donc $q$ est pair. $p$ et $q$ pairs : contradiction avec l'irréductibilité.

    **B. 1.** $\sqrt{8} = 2\sqrt{2}$. Si $2\sqrt{2} = r$ rationnel, alors $\sqrt{2} = \frac{r}{2}$ serait rationnel : impossible.

    **2.** $\left(\sqrt{2}\right)^2 - 1^2 = 2 - 1 = 1$ : oui, c'est même un entier.

    **3.** $1{,}4^2 = 1{,}96 < 2$ et $1{,}5^2 = 2{,}25 > 2$, donc $1{,}4 < \sqrt{2} < 1{,}5$.

## Évaluation 2

### Partie 1 — Automatismes (QCM)

**Question 1.** $\dfrac{3}{4} \times \dfrac{8}{15}$ est égal à :

a. $\frac{2}{5}$ ; b. $\frac{11}{19}$ ; c. $\frac{24}{19}$ ; d. $\frac{1}{2}$.

**Question 2.** $(-3)^2 - 3^2$ est égal à :

a. $-18$ ; b. $18$ ; c. $0$ ; d. $-6$.

**Question 3.** Le nombre $0{,}000\,72$ s'écrit en notation scientifique :

a. $72 \times 10^{-5}$ ; b. $7{,}2 \times 10^{-4}$ ; c. $7{,}2 \times 10^{4}$ ; d. $0{,}72 \times 10^{-3}$.

**Question 4.** La solution de $3x - 7 = 2$ est :

a. $3$ ; b. $\frac{5}{3}$ ; c. $-3$ ; d. $9$.

**Question 5.** Un prix de $60$ € baisse de $10\,\%$. Le nouveau prix est :

a. $50$ € ; b. $54$ € ; c. $59{,}40$ € ; d. $66$ €.

**Question 6.** La moyenne de $12$, $15$ et $9$ est :

a. $12$ ; b. $36$ ; c. $13$ ; d. $11$.

### Partie 2 — Exercice

1. On considère $I = [-4\,;\,3[$ et $J = ]1\,;\,+\infty[$. Déterminer $I \cap J$ et $I \cup J$. Le nombre $3$ appartient-il à $I \cup J$ ?
2. Calculer $|2 - \sqrt{5}|$ et $|\pi - 4|$.
3. Résoudre $|x - 1| = 4$, puis $|x + 3| < 2$.
4. Écrire l'intervalle $[-2\,;\,8]$ sous la forme $|x - a| \leq r$.
5. Un objet doit mesurer $50$ mm, avec une tolérance de $0{,}2$ mm. Traduire cette contrainte sur la longueur $L$ par une valeur absolue, puis par un intervalle.

??? success "Correction"
    **Partie 1**

    1. **a.** $\frac{24}{60}$. 2. **c.** $9 - 9$. 3. **b.** 4. **a.** 5. **b.** $60 \times 0{,}9$. 6. **a.** $\frac{36}{3}$.

    **Partie 2**

    **1.** $I \cap J = ]1\,;\,3[$ ; $I \cup J = [-4\,;\,+\infty[$. Oui, $3 \in J$, donc $3 \in I \cup J$.

    **2.** $\sqrt{5} > 2$, donc $|2 - \sqrt{5}| = \sqrt{5} - 2$. $\pi < 4$, donc $|\pi - 4| = 4 - \pi$.

    **3.** $x = -3$ ou $x = 5$. Puis $x \in ]-5\,;\,-1[$.

    **4.** Centre $3$, rayon $5$ : $|x - 3| \leq 5$.

    **5.** $|L - 50| \leq 0{,}2$, soit $L \in [49{,}8\,;\,50{,}2]$.

## Évaluation 3

### Partie 1 — Automatismes (QCM)

**Question 1.** $2^3 \times 2^4$ est égal à :

a. $2^{12}$ ; b. $4^7$ ; c. $2^7$ ; d. $2^{1}$.

**Question 2.** Lequel de ces nombres est divisible par $3$ ?

a. $1\,234$ ; b. $2\,025$ ; c. $1\,001$ ; d. $5\,555$.

**Question 3.** $(2k + 1) + (2k + 3)$ est égal à :

a. $4k + 4$ ; b. $4k + 3$ ; c. $2k + 4$ ; d. $4k^2 + 3$.

**Question 4.** Développer $(2k + 1)^2$ donne :

a. $4k^2 + 1$ ; b. $2k^2 + 4k + 1$ ; c. $4k^2 + 4k + 1$ ; d. $4k^2 + 2k + 1$.

**Question 5.** Une voiture roule à $90$ km/h. En $20$ minutes, elle parcourt :

a. $30$ km ; b. $45$ km ; c. $18$ km ; d. $4{,}5$ km.

**Question 6.** On lance un dé équilibré. La probabilité d'obtenir un multiple de $3$ est :

a. $\frac{1}{6}$ ; b. $\frac{1}{3}$ ; c. $\frac{1}{2}$ ; d. $\frac{2}{3}$.

### Partie 2 — Exercice

1. **Question de cours.** Démontrer que la somme de deux multiples d'un entier $a$ est un multiple de $a$.
2. Démontrer que la somme de deux entiers impairs consécutifs est un multiple de $4$.
3. Démontrer que pour tout entier $n$, $(n + 1)^2 - n^2$ est impair.
4. Démontrer que le carré d'un entier pair est un multiple de $4$.
5. L'affirmation « la somme de deux multiples de $3$ est un multiple de $6$ » est-elle vraie ? Justifier.

??? success "Correction"
    **Partie 1**

    1. **c.** 2. **b.** $2 + 0 + 2 + 5 = 9$. 3. **a.** 4. **c.** 5. **a.** $90 \times \frac{1}{3}$. 6. **b.** $\{3, 6\}$.

    **Partie 2**

    **1.** $b = ka$ et $c = k'a$ donnent $b + c = (k + k')a$, avec $k + k'$ entier.

    **2.** $(2k + 1) + (2k + 3) = 4k + 4 = 4(k + 1)$, multiple de $4$.

    **3.** $(n + 1)^2 - n^2 = 2n + 1$ : impair.

    **4.** $(2k)^2 = 4k^2$ : multiple de $4$.

    **5.** Fausse : contre-exemple $3 + 6 = 9$, qui n'est pas multiple de $6$.

## Évaluation 4

### Partie 1 — Automatismes (QCM)

**Question 1.** La décomposition en facteurs premiers de $72$ est :

a. $8 \times 9$ ; b. $2^3 \times 3^2$ ; c. $2^2 \times 3^3$ ; d. $2 \times 36$.

**Question 2.** $\dfrac{48}{36}$ est égal à :

a. $\frac{4}{3}$ ; b. $\frac{3}{4}$ ; c. $\frac{12}{9}$ et ne se simplifie plus ; d. $\frac{6}{5}$.

**Question 3.** Lequel de ces nombres est premier ?

a. $51$ ; b. $57$ ; c. $59$ ; d. $87$.

**Question 4.** $\sqrt{50}$ est égal à :

a. $25\sqrt{2}$ ; b. $5\sqrt{2}$ ; c. $2\sqrt{5}$ ; d. $10\sqrt{5}$.

**Question 5.** Une quantité augmente de $25\,\%$. Elle est multipliée par :

a. $0{,}25$ ; b. $1{,}025$ ; c. $1{,}25$ ; d. $25$.

**Question 6.** Sur une carte à l'échelle $\frac{1}{25\,000}$, $4$ cm représentent :

a. $1$ km ; b. $100$ m ; c. $10$ km ; d. $250$ m.

### Partie 2 — Exercice

1. Décomposer $252$ et $420$ en produits de facteurs premiers.
2. En déduire la fraction irréductible égale à $\frac{252}{420}$. Ce nombre est-il décimal ?
3. Quel est le plus grand diviseur commun à $252$ et $420$ ?
4. On veut découper une plaque rectangulaire de $252$ cm sur $420$ cm en carrés identiques, les plus grands possibles, sans perte. Quelle est la longueur du côté d'un carré ? Combien de carrés obtient-on ?
5. Le nombre $252 \times 7$ est-il un carré parfait ?

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **a.** 3. **c.** ($51 = 3 \times 17$, $57 = 3 \times 19$, $87 = 3 \times 29$). 4. **b.** 5. **c.** 6. **a.** $4 \times 25\,000 = 100\,000$ cm.

    **Partie 2**

    **1.** $252 = 2^2 \times 3^2 \times 7$ ; $420 = 2^2 \times 3 \times 5 \times 7$.

    **2.** $\frac{252}{420} = \frac{3}{5} = 0{,}6$ : il est décimal.

    **3.** Facteurs communs : $2^2 \times 3 \times 7 = 84$.

    **4.** Le côté doit diviser $252$ et $420$ ; le plus grand possible est $84$ cm. On obtient $\frac{252}{84} \times \frac{420}{84} = 3 \times 5 = 15$ carrés.

    **5.** $252 \times 7 = 2^2 \times 3^2 \times 7^2 = (2 \times 3 \times 7)^2 = 42^2$ : oui.
