## Évaluation 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** Si $f(x) = 2x^2 - 1$, alors $f(-3)$ vaut :

a. $35$ ; b. $17$ ; c. $-19$ ; d. $-7$.

**Question 2.** Les antécédents de $8$ par $x \mapsto x^2 - 1$ sont :

a. $63$ ; b. $3$ seulement ; c. $-3$ et $3$ ; d. $-9$ et $9$.

**Question 3.** La fonction $x \mapsto \dfrac{1}{x + 4}$ est définie sur :

a. $\mathbb{R}$ ; b. $\mathbb{R} \setminus \{4\}$ ; c. $\mathbb{R} \setminus \{-4\}$ ; d. $]-4\,;\,+\infty[$.

**Question 4.** $(-1)^3 - (-1)^2$ est égal à :

a. $0$ ; b. $-2$ ; c. $2$ ; d. $-1$.

**Question 5.** $\frac{2}{5}$ en pourcentage s'écrit :

a. $25\,\%$ ; b. $2{,}5\,\%$ ; c. $40\,\%$ ; d. $0{,}4\,\%$.

**Question 6.** Le périmètre d'un cercle de rayon $3$ est :

a. $9\pi$ ; b. $6\pi$ ; c. $3\pi$ ; d. $12\pi$.

### Partie 2 — Exercice

Soit $f$ la fonction définie par $f(x) = \dfrac{x^2 - 4}{x + 1}$.

1. Déterminer l'ensemble de définition $D$ de $f$.
2. Calculer $f(0)$, $f(1)$ et $f(-3)$.
3. Déterminer les antécédents de $0$ par $f$.
4. Le point $A(3\,;\,1{,}25)$ appartient-il à la courbe de $f$ ?
5. Déterminer les antécédents de $-2$ par $f$. *On pourra montrer que l'équation équivaut à $x(x + 2) = 0$.*

??? success "Correction"
    **Partie 1**

    1. **b.** $18 - 1$. 2. **c.** 3. **c.** 4. **b.** $-1 - 1$. 5. **c.** 6. **b.**

    **Partie 2**

    **1.** $x + 1 \neq 0$ : $D = \mathbb{R} \setminus \{-1\}$.

    **2.** $f(0) = -4$ ; $f(1) = -\frac{3}{2}$ ; $f(-3) = \frac{5}{-2} = -\frac{5}{2}$.

    **3.** $x^2 - 4 = 0$ et $x \neq -1$ : $x = 2$ ou $x = -2$.

    **4.** $f(3) = \frac{5}{4} = 1{,}25$ : oui.

    **5.** $\frac{x^2 - 4}{x + 1} = -2 \iff x^2 - 4 = -2x - 2$ (avec $x \neq -1$) $\iff x^2 + 2x = 0 \iff x(x + 2) = 0$. Antécédents : $0$ et $-2$.

## Évaluation 2

### Partie 1 — Automatismes (QCM)

**Question 1.** Le point $(2\,;\,5)$ appartient à la courbe de :

a. $x \mapsto x^2 + 1$ ; b. $x \mapsto 2x$ ; c. $x \mapsto x + 2$ ; d. $x \mapsto x^2 - 1$.

**Question 2.** La courbe d'une fonction $f$ coupe l'axe des ordonnées au point :

a. $(f(0)\,;\,0)$ ; b. $(0\,;\,f(0))$ ; c. $(0\,;\,0)$ ; d. $(1\,;\,f(1))$.

**Question 3.** Les solutions de $f(x) > 0$ se lisent :

a. là où la courbe est au-dessus de l'axe des abscisses ; b. là où la courbe est croissante ; c. sur l'axe des ordonnées ; d. là où la courbe coupe l'axe des ordonnées.

**Question 4.** $x^2 - 2x - 3$ est égal à :

a. $(x - 3)(x + 1)$ ; b. $(x + 3)(x - 1)$ ; c. $(x - 1)^2$ ; d. $(x - 3)^2$.

**Question 5.** $0{,}5 \times 0{,}04$ est égal à :

a. $0{,}2$ ; b. $0{,}02$ ; c. $0{,}002$ ; d. $2$.

**Question 6.** Un rectangle a une aire de $36$ cm² et une largeur de $4$ cm. Sa longueur est :

a. $32$ cm ; b. $9$ cm ; c. $14$ cm ; d. $6$ cm.

### Partie 2 — Exercice

On considère les fonctions $f(x) = x^2 - 2x - 3$ et $g(x) = x + 1$, définies sur $[-2\,;\,5]$.

1. Compléter le tableau de valeurs de $f$ pour $x$ entier de $-2$ à $5$, puis tracer les courbes de $f$ et $g$ dans un même repère.
2. Résoudre graphiquement $f(x) = 0$, puis $f(x) = g(x)$.
3. Résoudre graphiquement $f(x) \leq g(x)$.
4. Retrouver par le calcul les solutions de $f(x) = g(x)$. *On factorisera $x^2 - 3x - 4$.*

??? success "Correction"
    **Partie 1**

    1. **a.** 2. **b.** 3. **a.** 4. **a.** 5. **b.** 6. **b.**

    **Partie 2**

    **1.** $f(-2) = 5$, $f(-1) = 0$, $f(0) = -3$, $f(1) = -4$, $f(2) = -3$, $f(3) = 0$, $f(4) = 5$, $f(5) = 12$.

    **2.** $f(x) = 0$ : $x = -1$ ou $x = 3$. $f(x) = g(x)$ : les courbes se coupent en $x = -1$ et $x = 4$.

    **3.** La parabole est sous la droite entre $-1$ et $4$ : $S = [-1\,;\,4]$.

    **4.** $x^2 - 2x - 3 = x + 1 \iff x^2 - 3x - 4 = 0 \iff (x - 4)(x + 1) = 0$ : $x = 4$ ou $x = -1$.

## Évaluation 3

### Partie 1 — Automatismes (QCM)

**Question 1.** Une fonction croissante sur $[0\,;\,5]$ vérifie :

a. $f(1) \geq f(3)$ ; b. $f(1) \leq f(3)$ ; c. $f(1) = f(3)$ ; d. on ne peut rien dire.

**Question 2.** La fonction $x \mapsto -4x + 1$ est :

a. croissante sur $\mathbb{R}$ ; b. décroissante sur $\mathbb{R}$ ; c. constante ; d. croissante puis décroissante.

**Question 3.** Pour tout réel $x$, $(x - 3)^2$ est :

a. positif ou nul ; b. strictement positif ; c. négatif ; d. de signe variable.

**Question 4.** $(x - 1)^2 + 2$ est égal à :

a. $x^2 + 3$ ; b. $x^2 - 2x + 3$ ; c. $x^2 - 2x + 1$ ; d. $x^2 + 2x + 3$.

**Question 5.** Une quantité passe de $200$ à $150$. Elle a baissé de :

a. $50\,\%$ ; b. $25\,\%$ ; c. $33\,\%$ ; d. $75\,\%$.

**Question 6.** La fonction $x \mapsto x^2$ est :

a. paire ; b. impaire ; c. ni paire ni impaire ; d. croissante sur $\mathbb{R}$.

### Partie 2 — Exercice

Soit $f$ définie sur $\mathbb{R}$ par $f(x) = -2x^2 + 8x - 5$.

1. Calculer $f(0)$, $f(1)$, $f(2)$, $f(3)$ et $f(4)$. Conjecturer le maximum de $f$.
2. Démontrer que $f(x) = 3 - 2(x - 2)^2$, puis que $f$ admet un maximum que l'on précisera.
3. Soit $a < b \leq 2$. Montrer que $f(b) - f(a) = 2(b - a)(4 - a - b)$, et en déduire que $f$ est croissante sur $]-\infty\,;\,2]$.
4. On admet que $f$ est décroissante sur $[2\,;\,+\infty[$. Dresser le tableau de variations de $f$.

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **a.** 4. **b.** 5. **b.** $\frac{50}{200}$. 6. **a.**

    **Partie 2**

    **1.** $-5$ ; $1$ ; $3$ ; $1$ ; $-5$. Conjecture : maximum $3$ en $2$.

    **2.** $3 - 2(x^2 - 4x + 4) = -2x^2 + 8x - 5$. ✓ Comme $(x - 2)^2 \geq 0$, $f(x) \leq 3 = f(2)$ : maximum $3$, atteint en $2$.

    **3.** $f(b) - f(a) = -2(b^2 - a^2) + 8(b - a) = (b - a)\big(-2(b + a) + 8\big) = 2(b - a)(4 - a - b)$. Si $a < b \leq 2$ : $b - a > 0$ et $a + b < 4$, donc $4 - a - b > 0$. Ainsi $f(b) > f(a)$ : $f$ est croissante sur $]-\infty\,;\,2]$.

    **4.**

    | $x$ | $-\infty$ | | $2$ | | $+\infty$ |
    |---|---|---|---|---|---|
    | $f(x)$ | | $\nearrow$ | $3$ | $\searrow$ | |

## Évaluation 4

### Partie 1 — Automatismes (QCM)

**Question 1.** Le maximum de $x \mapsto 7 - (x + 1)^2$ sur $\mathbb{R}$ est :

a. $7$ ; b. $8$ ; c. $6$ ; d. $-1$.

**Question 2.** L'aire d'un triangle de base $10$ et de hauteur $x$ est :

a. $10x$ ; b. $5x$ ; c. $10 + x$ ; d. $\frac{x}{10}$.

**Question 3.** $x(20 - x)$ est égal à :

a. $20 - x^2$ ; b. $20x - x^2$ ; c. $20x - x$ ; d. $x^2 - 20x$.

**Question 4.** $100 - (x - 10)^2$ développé donne :

a. $-x^2 + 20x$ ; b. $-x^2 - 20x$ ; c. $x^2 - 20x$ ; d. $200 - x^2$.

**Question 5.** Le prix d'un article baisse de $20\,\%$ puis augmente de $25\,\%$. Au final, le prix :

a. a augmenté de $5\,\%$ ; b. n'a pas changé ; c. a baissé de $5\,\%$ ; d. a augmenté de $45\,\%$.

**Question 6.** On lance une pièce équilibrée trois fois. La probabilité d'obtenir trois « face » est :

a. $\frac{1}{3}$ ; b. $\frac{1}{6}$ ; c. $\frac{1}{8}$ ; d. $\frac{3}{8}$.

### Partie 2 — Exercice

Un fermier dispose de $40$ m de grillage pour clôturer un enclos rectangulaire **le long d'un mur** (le côté contre le mur n'a pas besoin de grillage). On note $x$ la longueur (en m) des deux côtés perpendiculaires au mur.

1. Montrer que le côté parallèle au mur mesure $40 - 2x$, et que l'aire de l'enclos est $A(x) = x(40 - 2x)$. Quelles sont les valeurs possibles de $x$ ?
2. Calculer $A(5)$, $A(10)$ et $A(15)$.
3. Montrer que $A(x) = 200 - 2(x - 10)^2$.
4. En déduire l'aire maximale et les dimensions de l'enclos correspondant.
5. Résoudre $A(x) \geq 150$. *On pourra montrer que l'inéquation équivaut à $(x - 10)^2 \leq 25$.*

??? success "Correction"
    **Partie 1**

    1. **a.** 2. **b.** 3. **b.** 4. **a.** 5. **b.** $0{,}8 \times 1{,}25 = 1$. 6. **c.**

    **Partie 2**

    **1.** Le grillage couvre $x + x + (40 - 2x) = 40$ m. Aire $x(40 - 2x)$. Il faut $x > 0$ et $40 - 2x > 0$ : $x \in ]0\,;\,20[$.

    **2.** $A(5) = 150$ ; $A(10) = 200$ ; $A(15) = 150$.

    **3.** $200 - 2(x^2 - 20x + 100) = -2x^2 + 40x = x(40 - 2x)$. ✓

    **4.** $(x - 10)^2 \geq 0$, donc $A(x) \leq 200 = A(10)$ : aire maximale $200$ m², pour $x = 10$ m (enclos de $10$ m sur $20$ m).

    **5.** $200 - 2(x - 10)^2 \geq 150 \iff (x - 10)^2 \leq 25 \iff -5 \leq x - 10 \leq 5 \iff 5 \leq x \leq 15$. $S = [5\,;\,15]$.
