## Évaluation 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** La solution de $2x + 7 = 1$ est :

a. $4$ ; b. $-3$ ; c. $3$ ; d. $-4$.

**Question 2.** Les solutions de $x^2 = 25$ sont :

a. $5$ ; b. $-5$ et $5$ ; c. $12{,}5$ ; d. $-25$ et $25$.

**Question 3.** $(x - 3)(x + 3)$ est égal à :

a. $x^2 - 9$ ; b. $x^2 + 9$ ; c. $x^2 - 6x + 9$ ; d. $x^2 - 6$.

**Question 4.** $\dfrac{3}{4}$ de $28$ est égal à :

a. $7$ ; b. $21$ ; c. $24$ ; d. $37{,}3$.

**Question 5.** Une augmentation de $50\,\%$ suivie d'une baisse de $50\,\%$ revient à :

a. ne rien changer ; b. une baisse de $25\,\%$ ; c. une hausse de $25\,\%$ ; d. une baisse de $50\,\%$.

**Question 6.** Le coefficient directeur de la droite passant par $(0\,;\,1)$ et $(2\,;\,7)$ est :

a. $3$ ; b. $4$ ; c. $\frac{1}{3}$ ; d. $6$.

### Partie 2 — Exercice

1. Résoudre : $5(x - 2) = 3x + 4$.
2. Résoudre : $(3x - 2)(x + 4) = 0$.
3. Résoudre : $x^2 = 5x$.
4. Résoudre : $(x + 2)^2 = 9$.
5. Factoriser $A = (2x + 1)^2 - (x - 3)^2$, puis résoudre $A = 0$.
6. Un nombre est tel que son carré est égal à son triple. Quels sont les nombres possibles ?

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **a.** 4. **b.** 5. **b.** $1{,}5 \times 0{,}5 = 0{,}75$. 6. **a.** $\frac{6}{2}$.

    **Partie 2**

    **1.** $5x - 10 = 3x + 4 \iff 2x = 14 \iff x = 7$.

    **2.** $S = \left\{-4\,;\,\frac{2}{3}\right\}$.

    **3.** $x^2 - 5x = 0 \iff x(x - 5) = 0$ : $S = \{0\,;\,5\}$.

    **4.** $x + 2 = 3$ ou $x + 2 = -3$ : $S = \{-5\,;\,1\}$.

    **5.** $A = \big[(2x + 1) - (x - 3)\big]\big[(2x + 1) + (x - 3)\big] = (x + 4)(3x - 2)$. $S = \left\{-4\,;\,\frac{2}{3}\right\}$.

    **6.** $x^2 = 3x \iff x(x - 3) = 0$ : $0$ ou $3$.

## Évaluation 2

### Partie 1 — Automatismes (QCM)

**Question 1.** L'expression $\dfrac{x + 1}{x - 4}$ n'est pas définie pour $x$ égal à :

a. $-1$ ; b. $4$ ; c. $0$ ; d. $-4$.

**Question 2.** Les solutions de $-3x > 12$ sont :

a. $x > -4$ ; b. $x < -4$ ; c. $x > 4$ ; d. $x < 4$.

**Question 3.** $\dfrac{1}{3} + \dfrac{1}{x}$ (pour $x \neq 0$) est égal à :

a. $\frac{2}{3x}$ ; b. $\frac{x + 3}{3x}$ ; c. $\frac{1}{3 + x}$ ; d. $\frac{2}{3 + x}$.

**Question 4.** L'intervalle des réels $x$ tels que $-1 < x \leq 4$ est :

a. $[-1\,;\,4]$ ; b. $]-1\,;\,4[$ ; c. $]-1\,;\,4]$ ; d. $[-1\,;\,4[$.

**Question 5.** $3 \times 10^{2} + 5 \times 10^{1}$ est égal à :

a. $8 \times 10^{3}$ ; b. $350$ ; c. $305$ ; d. $3\,050$.

**Question 6.** Un cycliste parcourt $45$ km en $1$ h $30$ min. Sa vitesse moyenne est :

a. $30$ km/h ; b. $45$ km/h ; c. $34{,}6$ km/h ; d. $67{,}5$ km/h.

### Partie 2 — Exercice

1. Résoudre $\dfrac{2x - 6}{x + 2} = 0$.
2. Résoudre $\dfrac{x + 5}{x - 1} = 3$.
3. Résoudre $\dfrac{4}{x} = x$.
4. Résoudre l'inéquation $3(x - 1) - 2 \leq 5x + 1$, et donner les solutions sous forme d'intervalle.
5. Un loueur propose : formule A, $30$ € plus $0{,}20$ € par km ; formule B, $0{,}50$ € par km. À partir de combien de kilomètres la formule A est-elle strictement plus avantageuse ?

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **b.** 4. **c.** 5. **b.** 6. **a.** $\frac{45}{1{,}5}$.

    **Partie 2**

    **1.** Interdite : $-2$. $2x - 6 = 0 \iff x = 3$. $S = \{3\}$.

    **2.** Interdite : $1$. $x + 5 = 3(x - 1) \iff 8 = 2x \iff x = 4$. $S = \{4\}$.

    **3.** Interdite : $0$. $4 = x^2 \iff x = \pm 2$. $S = \{-2\,;\,2\}$.

    **4.** $3x - 5 \leq 5x + 1 \iff -2x \leq 6 \iff x \geq -3$ : $S = [-3\,;\,+\infty[$.

    **5.** $30 + 0{,}2d < 0{,}5d \iff 30 < 0{,}3d \iff d > 100$ : au-delà de $100$ km.

## Évaluation 3

### Partie 1 — Automatismes (QCM)

**Question 1.** L'expression $-2x + 6$ est positive pour :

a. $x > 3$ ; b. $x < 3$ ; c. $x > -3$ ; d. $x < -3$.

**Question 2.** Le produit $(x - 1)(x - 5)$ est négatif pour $x$ dans :

a. $]-\infty\,;\,1[$ ; b. $]1\,;\,5[$ ; c. $]5\,;\,+\infty[$ ; d. $]-5\,;\,-1[$.

**Question 3.** $x^2 - 16 < 0$ a pour solutions :

a. $]-4\,;\,4[$ ; b. $]-\infty\,;\,4[$ ; c. $]-16\,;\,16[$ ; d. $]4\,;\,+\infty[$.

**Question 4.** La factorisation de $x^2 - 3x$ est :

a. $x(x - 3x)$ ; b. $x(x - 3)$ ; c. $(x - 3)^2$ ; d. $3x(x - 1)$.

**Question 5.** $25\,\%$ de $25\,\%$ font :

a. $50\,\%$ ; b. $6{,}25\,\%$ ; c. $0{,}625\,\%$ ; d. $62{,}5\,\%$.

**Question 6.** La médiane de la série $4 \,;\, 1 \,;\, 9 \,;\, 6 \,;\, 3$ est :

a. $9$ ; b. $4{,}6$ ; c. $4$ ; d. $6$.

### Partie 2 — Exercice

On considère $f(x) = (x - 3)(2x + 1) - (x - 3)^2$.

1. Factoriser $f(x)$ et montrer que $f(x) = (x - 3)(x + 4)$.
2. Dresser le tableau de signes de $f(x)$.
3. Résoudre $f(x) \geq 0$.
4. On pose $g(x) = \dfrac{x - 3}{x + 4}$.  
    a. Quelle est la valeur interdite ?  
    b. Dresser le tableau de signes de $g(x)$ et résoudre $g(x) < 0$.

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **a.** 4. **b.** 5. **b.** 6. **c.** Série ordonnée $1, 3, 4, 6, 9$.

    **Partie 2**

    **1.** $f(x) = (x - 3)\big[(2x + 1) - (x - 3)\big] = (x - 3)(x + 4)$.

    **2.**

    | $x$ | $-\infty$ | | $-4$ | | $3$ | | $+\infty$ |
    |---|---|---|---|---|---|---|---|
    | $x - 3$ | | $-$ | | $-$ | $0$ | $+$ | |
    | $x + 4$ | | $-$ | $0$ | $+$ | | $+$ | |
    | $f(x)$ | | $+$ | $0$ | $-$ | $0$ | $+$ | |

    **3.** $S = ]-\infty\,;\,-4] \cup [3\,;\,+\infty[$.

    **4. a.** $-4$.

    **b.** Mêmes signes que $f$, avec une double barre en $-4$ : $g(x) < 0 \iff x \in ]-4\,;\,3[$.

## Évaluation 4

### Partie 1 — Automatismes (QCM)

**Question 1.** L'aire d'un rectangle de dimensions $x$ et $x + 2$ est :

a. $2x + 2$ ; b. $x^2 + 2$ ; c. $x^2 + 2x$ ; d. $4x + 4$.

**Question 2.** $(x + 5)(x - 3)$ est égal à :

a. $x^2 + 2x - 15$ ; b. $x^2 - 15$ ; c. $x^2 - 2x - 15$ ; d. $x^2 + 8x - 15$.

**Question 3.** Le périmètre d'un carré d'aire $49$ cm² est :

a. $7$ cm ; b. $14$ cm ; c. $28$ cm ; d. $196$ cm.

**Question 4.** Si $x$ est une longueur en cm, l'équation $x^2 = 18$ a pour solution :

a. $9$ ; b. $3\sqrt{2}$ ; c. $-3\sqrt{2}$ et $3\sqrt{2}$ ; d. $\sqrt{9}$.

**Question 5.** Un prix passe de $25$ € à $20$ €. Le taux d'évolution est :

a. $-5\,\%$ ; b. $-20\,\%$ ; c. $-25\,\%$ ; d. $+25\,\%$.

**Question 6.** Si $P(A) = 0{,}3$, alors $P\left(\overline{A}\right)$ vaut :

a. $0{,}3$ ; b. $0{,}6$ ; c. $0{,}7$ ; d. $1{,}3$.

### Partie 2 — Exercice

Un jardin rectangulaire mesure $12$ m sur $8$ m. On veut l'entourer d'une allée de largeur constante $x$ mètres, de sorte que l'**aire de l'allée** soit égale à l'aire du jardin.

1. Exprimer, en fonction de $x$, les dimensions du rectangle formé par le jardin et l'allée.
2. Montrer que le problème revient à résoudre $(12 + 2x)(8 + 2x) = 192$.
3. Montrer que cette équation s'écrit $4x^2 + 40x - 96 = 0$, puis $x^2 + 10x - 24 = 0$.
4. Vérifier que $x^2 + 10x - 24 = (x + 12)(x - 2)$ et conclure.
5. Pour quelles largeurs $x$ l'aire de l'allée est-elle **inférieure** à celle du jardin ?

??? success "Correction"
    **Partie 1**

    1. **c.** 2. **a.** 3. **c.** 4. **b.** Une longueur est positive. 5. **b.** $\frac{-5}{25}$. 6. **c.**

    **Partie 2**

    **1.** $(12 + 2x)$ m sur $(8 + 2x)$ m.

    **2.** Aire totale $=$ jardin $+$ allée $= 96 + 96 = 192$ m².

    **3.** $96 + 24x + 16x + 4x^2 = 192 \iff 4x^2 + 40x - 96 = 0$, puis on divise par $4$.

    **4.** $(x + 12)(x - 2) = x^2 - 2x + 12x - 24$. ✓ Solutions $-12$ et $2$ ; $x > 0$, donc l'allée mesure $2$ m de large.

    **5.** On veut $x^2 + 10x - 24 < 0$ avec $x > 0$ : $(x + 12)(x - 2) < 0 \iff -12 < x < 2$. Avec $x > 0$ : $x \in ]0\,;\,2[$.
