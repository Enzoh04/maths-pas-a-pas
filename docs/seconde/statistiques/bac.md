## Évaluation 1

### Partie 1 — Automatismes (QCM)

Pour chaque question, une seule réponse est exacte. Aucune justification n'est demandée.

**Question 1.** Augmenter de $8\,\%$, c'est multiplier par :

a. $0{,}08$ ; b. $1{,}8$ ; c. $1{,}08$ ; d. $0{,}92$.

**Question 2.** Un prix passe de $25$ € à $30$ €. Le taux d'évolution est :

a. $+5\,\%$ ; b. $+20\,\%$ ; c. $+16{,}7\,\%$ ; d. $+25\,\%$.

**Question 3.** Une baisse de $10\,\%$ suivie d'une baisse de $10\,\%$ revient à une baisse de :

a. $20\,\%$ ; b. $19\,\%$ ; c. $21\,\%$ ; d. $1\,\%$.

**Question 4.** $30\,\%$ de $70\,\%$ font :

a. $21\,\%$ ; b. $100\,\%$ ; c. $40\,\%$ ; d. $2{,}1\,\%$.

**Question 5.** $\dfrac{3}{0{,}75}$ est égal à :

a. $0{,}25$ ; b. $4$ ; c. $2{,}25$ ; d. $40$.

**Question 6.** La solution de $1{,}25x = 100$ est :

a. $125$ ; b. $75$ ; c. $80$ ; d. $98{,}75$.

### Partie 2 — Exercice

Le prix d'un smartphone est de $400$ € en janvier.

1. En février, son prix augmente de $10\,\%$. Calculer son prix en février.
2. En mars, son prix baisse de $20\,\%$ par rapport à février. Calculer le prix en mars, et le taux d'évolution global de janvier à mars.
3. Quel taux d'augmentation faudrait-il appliquer en avril pour revenir au prix de janvier ? (Arrondir à $0{,}1\,\%$ ; on donne $\frac{1}{0{,}88} \approx 1{,}136$.)
4. Un autre modèle coûte $468$ € après une hausse de $4\,\%$. Quel était son prix avant la hausse ?

??? success "Correction"
    **Partie 1**

    1. **c.** 2. **b.** $\frac{5}{25}$. 3. **b.** $0{,}9^2 = 0{,}81$. 4. **a.** 5. **b.** 6. **c.** $\frac{100}{1{,}25}$.

    **Partie 2**

    **1.** $400 \times 1{,}1 = 440$ €.

    **2.** $440 \times 0{,}8 = 352$ €. Global : $1{,}1 \times 0{,}8 = 0{,}88$, soit une baisse de $12\,\%$.

    **3.** Coefficient $\frac{1}{0{,}88} \approx 1{,}136$ : une hausse d'environ $13{,}6\,\%$.

    **4.** $\frac{468}{1{,}04} = 450$ €.

## Évaluation 2

### Partie 1 — Automatismes (QCM)

**Question 1.** La médiane de $3\,;\,8\,;\,5\,;\,10\,;\,7$ est :

a. $5$ ; b. $6{,}6$ ; c. $7$ ; d. $8$.

**Question 2.** La moyenne de $3\,;\,8\,;\,5\,;\,10\,;\,7$ est :

a. $6{,}6$ ; b. $7$ ; c. $33$ ; d. $6$.

**Question 3.** Si l'on ajoute $2$ à toutes les valeurs d'une série, l'écart type :

a. augmente de $2$ ; b. est multiplié par $2$ ; c. ne change pas ; d. augmente de $4$.

**Question 4.** Pour une série de $40$ valeurs rangées, le premier quartile est la valeur de rang :

a. $4$ ; b. $10$ ; c. $11$ ; d. $20$.

**Question 5.** $\sqrt{16 + 9}$ est égal à :

a. $7$ ; b. $5$ ; c. $25$ ; d. $12{,}5$.

**Question 6.** Une moyenne de $12$ sur $5$ notes correspond à une somme de :

a. $17$ ; b. $2{,}4$ ; c. $60$ ; d. $12$.

### Partie 2 — Exercice

On a relevé le nombre de livres lus pendant l'été par $25$ élèves.

| Nombre de livres | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---|---|---|---|---|---|
| Effectif | $3$ | $6$ | $7$ | $5$ | $3$ | $1$ |

1. Calculer l'effectif cumulé croissant de chaque valeur.
2. Déterminer la médiane, le premier et le troisième quartile. Calculer l'écart interquartile.
3. Calculer la moyenne.
4. Quelle est la proportion d'élèves ayant lu au moins $3$ livres ?
5. Tracer le diagramme en boîte de la série.

??? success "Correction"
    **Partie 1**

    1. **c.** Série rangée $3, 5, 7, 8, 10$. 2. **a.** $\frac{33}{5}$. 3. **c.** 4. **b.** 5. **b.** 6. **c.**

    **Partie 2**

    **1.** $3, 9, 16, 21, 24, 25$.

    **2.** $N = 25$ : médiane au rang $13$, soit $2$. $Q_1$ au rang $\lceil 6{,}25 \rceil = 7$ : $1$. $Q_3$ au rang $\lceil 18{,}75 \rceil = 19$ : $3$. Écart interquartile $2$.

    **3.** $\frac{0 + 6 + 14 + 15 + 12 + 5}{25} = \frac{52}{25} = 2{,}08$.

    **4.** $\frac{5 + 3 + 1}{25} = \frac{9}{25} = 36\,\%$.

    **5.** Boîte de $1$ à $3$, médiane $2$, moustaches de $0$ à $5$.

## Évaluation 3

### Partie 1 — Automatismes (QCM)

**Question 1.** Le centre de la classe $[20\,;\,30[$ est :

a. $20$ ; b. $25$ ; c. $30$ ; d. $10$.

**Question 2.** La moyenne de deux groupes de $10$ et $30$ élèves, de moyennes $8$ et $12$, est :

a. $10$ ; b. $11$ ; c. $9$ ; d. $20$.

**Question 3.** Si toutes les valeurs d'une série sont multipliées par $3$, la moyenne :

a. ne change pas ; b. est multipliée par $3$ ; c. augmente de $3$ ; d. est multipliée par $9$.

**Question 4.** $\frac{18}{40}$ en pourcentage s'écrit :

a. $18\,\%$ ; b. $45\,\%$ ; c. $40\,\%$ ; d. $22\,\%$.

**Question 5.** $5 \times 4 + 15 \times 6$ est égal à :

a. $110$ ; b. $120$ ; c. $100$ ; d. $90$.

**Question 6.** La fonction $x \mapsto 3x - 6$ s'annule en :

a. $-2$ ; b. $2$ ; c. $6$ ; d. $3$.

### Partie 2 — Exercice

On a mesuré la durée (en minutes) de $40$ appels reçus par un service client.

| Durée | $[0\,;\,4[$ | $[4\,;\,8[$ | $[8\,;\,12[$ | $[12\,;\,16[$ | $[16\,;\,20[$ |
|---|---|---|---|---|---|
| Effectif | $6$ | $14$ | $10$ | $6$ | $4$ |

1. Calculer une valeur approchée de la durée moyenne d'un appel.
2. Calculer la fréquence des appels de moins de $8$ minutes.
3. Dans quelle classe se trouve la médiane ?
4. Un second service a une durée moyenne de $9$ minutes avec un écart type de $2$ min ; le premier service a un écart type d'environ $4{,}7$ min. Comparer les deux services.

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** $\frac{80 + 360}{40}$. 3. **b.** 4. **b.** 5. **a.** 6. **b.**

    **Partie 2**

    **1.** Centres $2, 6, 10, 14, 18$ : $\frac{12 + 84 + 100 + 84 + 72}{40} = \frac{352}{40} = 8{,}8$ min.

    **2.** $\frac{6 + 14}{40} = 50\,\%$.

    **3.** Les rangs $20$ et $21$ : effectifs cumulés $6, 20, 30$, donc le rang $20$ est dans $[4\,;\,8[$ et le rang $21$ dans $[8\,;\,12[$ ; la médiane est autour de $8$ min.

    **4.** Durées moyennes voisines ($8{,}8$ et $9$ min), mais le premier service est beaucoup plus irrégulier (écart type plus de deux fois plus grand).

## Évaluation 4

### Partie 1 — Automatismes (QCM)

**Question 1.** Dans un groupe de $80$ personnes, $20$ sont gauchères. La proportion de gauchers est :

a. $20\,\%$ ; b. $25\,\%$ ; c. $40\,\%$ ; d. $4\,\%$.

**Question 2.** Parmi les $20$ gauchers, $5$ sont des filles. La proportion de filles parmi les gauchers est :

a. $5\,\%$ ; b. $25\,\%$ ; c. $6{,}25\,\%$ ; d. $20\,\%$.

**Question 3.** La proportion de filles gauchères dans le groupe de $80$ est :

a. $25\,\%$ ; b. $6{,}25\,\%$ ; c. $5\,\%$ ; d. $20\,\%$.

**Question 4.** $\frac{45}{60}$ est égal à :

a. $0{,}45$ ; b. $0{,}75$ ; c. $0{,}6$ ; d. $1{,}33$.

**Question 5.** $(1 - 0{,}2)^2$ est égal à :

a. $0{,}64$ ; b. $0{,}6$ ; c. $0{,}96$ ; d. $0{,}04$.

**Question 6.** L'équation $x^2 = 0{,}81$ a pour solution positive :

a. $0{,}09$ ; b. $0{,}9$ ; c. $0{,}405$ ; d. $9$.

### Partie 2 — Exercice

Une enquête porte sur $600$ lycéens : on leur demande s'ils utilisent principalement le bus, le vélo ou la voiture pour venir au lycée. $250$ sont internes au lycée ou habitent en ville (« urbains »), les autres sont « ruraux ».

| | Bus | Vélo | Voiture | Total |
|---|---|---|---|---|
| Urbains | $100$ | $120$ | $30$ | $250$ |
| Ruraux | $210$ | $35$ | $105$ | |
| Total | | | | $600$ |

1. Compléter le tableau.
2. Calculer la fréquence marginale des utilisateurs du vélo.
3. Calculer la proportion de cyclistes parmi les urbains, puis parmi les ruraux. Commenter.
4. Quelle est la proportion d'urbains parmi les cyclistes ?
5. On veut augmenter de $20\,\%$ le nombre de cyclistes ruraux l'an prochain. Combien seraient-ils ?

??? success "Correction"
    **Partie 1**

    1. **b.** 2. **b.** 3. **b.** $\frac{5}{80}$. 4. **b.** 5. **a.** 6. **b.**

    **Partie 2**

    **1.** Ruraux : total $350$. Totaux des colonnes : bus $310$, vélo $155$, voiture $135$.

    **2.** $\frac{155}{600} \approx 25{,}8\,\%$.

    **3.** Urbains : $\frac{120}{250} = 48\,\%$ ; ruraux : $\frac{35}{350} = 10\,\%$. Le vélo est beaucoup plus utilisé par les urbains (trajets plus courts).

    **4.** $\frac{120}{155} \approx 77{,}4\,\%$.

    **5.** $35 \times 1{,}2 = 42$.
