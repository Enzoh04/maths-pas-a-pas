## Comment utiliser ce contenu

- Les documents sont proposés **à titre pédagogique**, sans garantie d'exactitude ni d'exhaustivité.

- Avant d'apprendre un résultat par cœur, prends l'habitude de **vérifier les calculs** toi-même. C'est aussi une excellente façon de progresser.
